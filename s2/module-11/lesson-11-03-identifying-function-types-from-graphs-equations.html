💡 EXPLORING THE MATH

In Algebra 2, you will work with many different types of functions. Although they may look very different at first, each function type has specific characteristics that help you recognize it quickly. Being able to identify a function type from its equation or graph allows you to predict its behavior, describe its key features, and apply it appropriately in real-world situations. In this lesson, you will learn how to determine whether a function is linear, quadratic, exponential, logarithmic, cubic, square root, cube root, absolute value, or rational by analyzing both equations and graphs.

Identifying Function Types from Equations

When identifying a function from an equation, focus on the structure of the equation. Look at:

  • Where the variable appears

  • The highest exponent

  • Whether the variable is inside a root, denominator, or absolute value

  • Whether the variable is in the exponent

Below are key characteristics for each function type.

Linear Function \(f(x)=mx+b\)

  • Highest exponent is 1

  • Variable is not squared, cubed, or inside a root

  • No variable in the denominator or exponent
Quadratic Function \(f(x)=ax^2+bx+c\)

  • Highest exponent is 2

  • No variable in denominator or exponent
Cubic Function \(f(x)=ax^3+bx^2+cx+d\)

  • Highest exponent is 3

  • No variable in denominator or exponent
Exponential Function \(f(x)=ab^x\)

  • The variable is in the exponent

  • Base is a positive constant

  • Represents growth or decay
Logarithmic Function

\(f(x)=\log_{b}{x}\)

\(f(x)=\ln{x}\)

  • Variable is inside a logarithm

  • Inverse of an exponential function
Square Root Function \(f(x)=a\sqrt{x-h}+k\)

  • Variable is inside a square root

  • Graph begins at a starting point
Cube Root Function \(f(x)=a\sqrt[3]{x-h}+k\)

  • Variable is inside a cube root

  • Graph extends in both directions
Absolute Value Function \(f(x)=a|x-h|+k\)

  • Variable is inside absolute value symbols

  • Produces a V-shaped graph
Rational Function \(f(x)=\frac{p(x)}{q(x)}\)

  • Variable appears in the denominator

  • Variable may also appear in the numerator

  • May contain vertical asymptotes

Identifying Function Types from Graphs

When looking at a graph, focus on the shape and behavior.

Linear Function

  • Straight line

  • Constant rate of change
Quadratic Function

  • Parabola (U-shaped or upside down)

  • Has a vertex
Cubic Function

  • S-shaped curve

  • May have one or two turning points

  • Opposite end behavior directions
Exponential Function

  • Rapid growth or decay

  • Has a horizontal asymptote

  • Does not cross the asymptote
Logarithmic Function

  • Increases or decreases slowly

  • Has a vertical asymptote

  • Only exists on one side of asymptote
Square Root Function

  • Starts at an endpoint

  • Curves gradually in one direction

  • Domain is restricted
Cube Root Function

  • S-shaped curve

  • Extends infinitely in both directions

  • No asymptotes
Absolute Value Function

  • V-shaped graph

  • Sharp corner at the vertex
Rational Function

  • Has vertical and/or horizontal asymptotes

  • May have two separate branches

Conclusion

Recognizing function types becomes much easier when you focus on structure and shape. When analyzing an equation, examine where the variable appears and identify the highest power or special structure, such as roots, absolute values, denominators, or exponents. When analyzing a graph, look for key features such as straight lines, parabolas, asymptotes, endpoints, turning points, or symmetry. By consistently applying these strategies, you will quickly and confidently determine function types in multiple representations.
