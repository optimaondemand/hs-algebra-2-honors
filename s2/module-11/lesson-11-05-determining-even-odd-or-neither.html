📚 VOCABULARY

Absolute Value Function: A function that includes an absolute value expression and produces a V-shaped graph, typically written in the form \(f(x)=a|x-h|+k\).

Even Function: A function in which \(f(-x)=f(x)\) for all values in the domain, meaning the graph is symmetric across the y-axis.

Function Notation: A way of writing functions using symbols such as \(f(x)\), which represents the output value of a function for a given input \(x\).

Linear Function: A function written in the form \(f(x)=mx+b\), whose graph is a straight line and has a constant rate of change.

Neither: A classification for a function that is not even and not odd because it does not satisfy the conditions for either type of symmetry.

Odd Function: A function in which \(f(-x)=-f(x)\) for all values in the domain, meaning the graph is symmetric about the origin.

Origin Symmetry: A type of symmetry where a graph looks the same after being rotated 180 degrees around the origin.

Polynomial Function: A function made up of terms that include constants and variables raised to nonnegative integer powers, such as \(f(x)=ax^n+bx^{n-1}+...+c\).

Rational Function: A function that can be written as the ratio of two polynomials, typically in the form \(f(x)=\frac{p(x)}{q(x)}\)​ where \(q(x)\neq 0\).

Root Function: A function in which the variable appears inside a radical expression, such as a square root or cube root function.

Symmetry: A property of a graph where one part of the graph is a mirror image or rotation of another part.

X-Axis Symmetry: A type of symmetry in which a graph is reflected across the x-axis, meaning points above the axis have corresponding points below it.

Y-Axis Symmetry: A type of symmetry in which the left side of a graph is a mirror image of the right side across the y-axis.

💡 EXPLORING THE MATH

One of the most useful ways to classify a function is by its symmetry. When a function has a particular kind of symmetry, we say it is either even or odd. Functions that do not fit either category are called neither. Recognizing whether a function is even, odd, or neither helps us understand its behavior, sketch its graph more efficiently, and simplify complicated expressions in future mathematics courses. In this lesson, you will develop this skill in three stages: first by examining graphs, then by analyzing tables of values, and finally by working directly with equations. Each stage builds on the last, and by the end of the reading you will be able to classify any function — no matter how it is presented — quickly and confidently. The functions you will encounter include linear, absolute value, polynomial, root, and rational functions, which together make up the core function families you have studied so far this year.

 

Identifying Even, Odd, or Neither from Graphs

The key to classifying a function from its graph lies in recognizing symmetry. There are two types of symmetry that matter for this classification.

Even Functions — Y-Axis Symmetry

A function is even if its graph is symmetric about the y-axis. This means the left side of the graph is a mirror image of the right side. If you fold the graph along the y-axis, the two halves match perfectly.

Key observation: For every point (x, y) on the graph, the point (−x, y) is also on the graph.

Examples of even function types: parabolas (\(y=x^2\)), even-degree polynomials centered at the origin, and absolute value functions centered on the y-axis.

Example:

Notice in the graph how the points (−2, 2) and (2, 2) share the same y-value but opposite x-values — this is the defining pattern of y-axis symmetry.

 

Odd Functions — Origin Symmetry

A function is odd if its graph has rotational symmetry about the origin. If you rotate the graph 180° around the origin, it looks exactly the same.

Key observation: For every point (x, y) on the graph, the point (−x, −y) is also on the graph.

Examples of odd function types: cubic functions like \(y=x^3\), odd-degree polynomials through the origin, and the rational function \(y=\frac{1}{x}\).

Example:

Notice in this graph, the points (1.5, 1.875) and (−1.5, −1.875) are reflections through the origin — both the x and y values are negated.


What about "neither"?

If a graph has neither y-axis symmetry nor origin symmetry, the function is classified as neither even nor odd. This is by far the most common classification — most functions in the real world fall into this category. Root functions like \(y=\sqrt{x}\), linear functions like \(y=2x+1\) (shifted off the origin), and most shifted functions are neither.

Step-by-Step: How to Check a Graph

When given a graph, use this checklist:

1. Draw or imagine a vertical line along the y-axis. Ask yourself: Does the left half mirror the right half? If yes → the function is even.

2. If not symmetric about the y-axis, ask: does every point (x, y) have a corresponding point (−x, −y) on the graph? Equivalently, does the graph look the same after a 180° rotation about the origin? If yes → the function is odd.

3. If neither test passes → the function is neither even nor odd.

Example 1

Given the graph:

What type of function symmetry does it have?

A. Odd
B. Even
C. Neither

Solution:

We will compare the points on the graph to determine if there is any symmetry over the y-axis or around the origin.

On this graph, we can compare \((-2,1)\) with \((2,1)\).

When x=2, f(2)=1. When x=-2, f(-2)=1.

Replacing x with -x results in the same y-value.

This follows the y-axis symmetry.

Therefore, the function is even.

Answer: B

Identifying Even, Odd, or Neither in Tables of Values

When a function is represented by a table of values rather than a graph, you are looking at individual coordinates instead of a continuous curve. The good news is that the same symmetry rules apply — you just need to know what patterns to look for in the numbers.

Look at pairs of inputs:

  • \(x\) and \(-x\)

Then compare their outputs.

 

Translating Symmetry into Number Patterns

  • Even function (y-axis symmetry): f(−x) = f(x) for all x in the table. In other words, opposite x-values produce the same output. If x = 3 gives f(3) = 9, then x = −3 must give f(−3) = 9.

  • Odd function (origin symmetry): f(−x) = −f(x) for all x in the table. Opposite x-values produce opposite outputs. If x = 3 gives f(3) = 9, then x = −3 must give f(−3) = −9.

  • Neither: Neither pattern holds consistently for all pairs of opposite x-values in the table.


Checking a Table: What to Do

Follow these steps every time you analyze a table:

  1. Identify pairs of opposite x-values in the table, such as (−3, 3), (−2, 2), (−1, 1).
  2. For each pair, compare the f(x) values. Write both values down side by side.
  3. Ask: Are the outputs equal? (even test) Or are they opposites, meaning they add to zero? (odd test)
  4. The test must hold for EVERY pair. One counterexample is enough to rule out even or odd.

 

Note: If x = 0 appears in the table, f(0) must equal 0 for any odd function, because f(−0) = −f(0) means f(0) = −f(0), which only works if f(0) = 0. Even functions can have any value at x = 0.

Example 1

Given the table of values.

x y
-10 -2
-5 -4
0 -6
5 -4
10 -2

Determine if the function is even, odd, or neither.

Solution:

Step 1: Identify pairs: \((-10,-2), (-5,-4), (5,-4), (10,-2)\).

Step 2: Compare outputs:

\(f(-10)=-2\) and \(f(10)=-2\)  →  They are the same (\(-2=-2\)). ✓ Even test.

\(f(-5)=-4\) and \(f(5)=-4\)  →  They are the same (\(-4=-4\)). ✓ Even test.

f(0) = any number  Ok for even functions. ✓

Conclusion: The function is even.

Answer: Even

Solution:

Step 1: Identify pairs: \((-1,7), (0,0), (1,-7)\).

Step 2: Compare outputs:

\(f(-1)=7\) and \(f(1)=-7\)  →  They are opposites. ✓ Odd test.

\(f(0)=0\) → Required for odd functions. ✓

Identifying Even, Odd, or Neither from Equations

The most powerful and efficient method for classifying a function is the algebraic test. Instead of relying on a picture or a set of data points, we use the equation directly.

The test is based on the same definitions we have been using, but now expressed with function notation: we evaluate f(−x) and compare it to f(x) and −f(x).

Understanding f(−x)

To find \(f(-x)\), replace every occurrence of x in the equation with \((-x)\), then simplify.

Example: If \(f(x)=3x^2-5\), then:

\(f(-x)=3(-x)^2-5=3(x^2)-5=3x^2-5\)

Since \(f(-x)=f(x)\), the function is even.

 

The Three-Step Algebraic Test

Step 1: Find f(−x) by substituting −x for every x in the equation. Simplify completely.

Step 2: Compare f(−x) to f(x) and to −f(x).

Step 3: If f(−x) = f(x):  the function is EVEN

          If f(−x) = −f(x):  the function is ODD

          If neither:  the function is NEITHER

 

Key Patterns to Know

Before practicing, here are some helpful shortcuts to recognize:

Powers of \((-x)\)): \((-x)^2=x^2\) (even power → stays positive)  |  \((-x)^3=-x^3\) (odd power → becomes negative)

Polynomial shortcut: A polynomial with ONLY even-degree terms (x², x⁴, constants) is always even. A polynomial with ONLY odd-degree terms (x, x³, x⁵) and no constant term is always odd. A mix of both is neither.

Absolute value: \(|-x|=|x|\), so \(f(x)=|x|\) is even. Any absolute value function centered at the origin will be even.

Root functions: (cube root) is odd because . But (square root) is neither because its domain excludes negative x.

Quick Reference Summary

Even:   f(−x) = f(x)   →  y-axis symmetry   →  same outputs for opposite inputs

Odd:    f(−x) = −f(x)  →  origin symmetry  →  opposite outputs for opposite inputs

Neither: Neither condition holds for all x



Conclusion

In this reading, you explored three different methods for classifying a function as even, odd, or neither — through its graph, its table of values, and its equation. At the core of all three methods is the same idea: symmetry. Even functions mirror themselves across the y-axis, odd functions rotate onto themselves around the origin, and functions that lack both of these symmetries are neither. When examining graphs, you look for visual symmetry. When working with tables, you search for numerical patterns by comparing f(−x) to f(x) and −f(x). When working with equations, you apply the algebraic test by substituting −x directly into the formula. These three representations are different windows into the same underlying function, and being fluent with all three will serve you well as you continue into pre-calculus and beyond. As you practice, pay close attention to the structure of each function — the types of terms, the degrees of polynomials, and the placement of any shifts — because these features are often the fastest clues to a function's symmetry.
