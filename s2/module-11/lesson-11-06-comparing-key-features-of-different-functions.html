📚 VOCABULARY

Asymptote: A line that a curve approaches but never actually reaches as it extends toward infinity.

Cube Root Function: A function of the form \(f(x) = \sqrt[3]{x}\) that returns the cube root of a given input value.

Cubic Function: A polynomial function of degree three, written in the form \(f(x) = ax^3 + bx^2 + cx + d\), where \(a \neq 0\).

Domain: The set of all possible input values (\(x\)-values) for which a function is defined.

End Behavior: The description of how a function's output values behave as the input values approach positive or negative infinity.

Exponential Function: A function of the form \(f(x) = ab^x\), where the variable appears as an exponent and \(b\) is a positive constant not equal to 1.

Function: A relation in which each input value is paired with exactly one output value.

Intercept: A point where a graph crosses or touches an axis; an \(x\)-intercept occurs where the graph meets the \(x\)-axis, and a \(y\)-intercept occurs where the graph meets the \(y\)-axis.

Interval of Decrease: A portion of a function's domain over which the output values are getting smaller as the input values increase.

Interval of Increase: A portion of a function's domain over which the output values are getting larger as the input values increase.

Linear Function: A function of the form \(f(x) = mx + b\) whose graph is a straight line, where \(m\) represents the slope and \(b\) represents the \(y\)-intercept.

Logarithmic Function: A function of the form \(f(x) = \log_b(x)\) that is the inverse of an exponential function, representing the exponent to which a base must be raised to produce a given value.

Maximum: The highest output value of a function, either over its entire domain (absolute maximum) or over a specific interval (relative maximum).

Minimum: The lowest output value of a function, either over its entire domain (absolute minimum) or over a specific interval (relative minimum).

Quadratic Function: A polynomial function of degree two, written in the form \(f(x) = ax^2 + bx + c\), where \(a \neq 0\), whose graph forms a parabola.

Range: The set of all possible output values (\(y\)-values) produced by a function.

Rate Of Change: A measure of how much one quantity changes relative to another; in a function, it describes how the output changes as the input changes.

Rational Function: A function that can be written as the ratio of two polynomials, expressed as \(f(x) = \frac{p(x)}{q(x)}\), where \(q(x) \neq 0\).

Square Root Function: A function of the form \(f(x) = \sqrt{x}\) that returns the non-negative square root of a given input value.

💡 EXPLORING THE MATH

As you have worked through different types of functions — linear, quadratic, cubic, square root, cube root, rational, exponential, logarithmic, and absolute value — you have learned that each has its own unique shape, behavior, and set of characteristics. But what happens when we place two functions side by side? Being able to compare the key features of functions is one of the most powerful skills in algebra and pre-calculus. It allows you to understand not just how one function behaves on its own, but how and why that behavior differs from another. In this lesson, you will learn how to identify and compare the most important features of different function families using equations, graphs, and tables of values.

What Does It Mean to Compare Key Features?

When we compare the key features of two or more functions, we examine specific characteristics that describe how each function behaves — and then note the similarities and differences between them. Rather than describing one function in isolation, comparing features helps us see patterns across function families and develop a richer understanding of mathematical behavior.

The key features we will focus on in this lesson are:

  • Rate of Change on a Given Interval — How fast is the function increasing or decreasing over a specific section of its graph?
  • End Behavior — What happens to the output values as \(x\) approaches positive or negative infinity?
  • Maximums and Minimums — Does the function have a highest or lowest point, and if so, where?
  • Domain and Range — What input values are allowed, and what output values are produced?
  • \(x\)- and \(y\)-Intercepts — Where does the function cross or touch the axes?
  • Intervals of Increase and Decrease — Over which portions of the domain is the function going up or going down?

 

Understanding Each Key Feature

Average Rate of Change (AROC) on a Given Interval: For any two functions, we can calculate the average rate of change on an interval \([a, b]\) using the formula:

\(\displaystyle \text{Average Rate of Change}=AROC = \frac{f(b) - f(a)}{b - a}\)

For a linear function, this value is always constant — it equals the slope. For nonlinear functions, this value changes depending on which interval you choose. Comparing average rates of change tells you which function is growing faster or slower over the same interval.


End Behavior: End behavior describes what the output of a function does as \(x \to \infty\) (far to the right) or \(x \to -\infty\) (far to the left). We use arrow notation to describe this. For example, if a function rises on both ends: as \(x \to \infty\), \(f(x) \to \infty\) and as \(x \to -\infty\), \(f(x) \to \infty\). Different function families have characteristic end behaviors — exponential functions approach a horizontal asymptote on one end, while odd-degree polynomial functions go in opposite directions on each end.


Maximums and Minimums: A maximum is the highest output value of a function, and a minimum is the lowest. An absolute maximum or minimum is a single highest or lowest point over the entire domain. A relative (local) maximum or minimum is a peak or valley in a specific region. Linear, exponential, root, and logarithmic functions have no maximum or minimum because they continue without bound. Quadratic functions have exactly one vertex — either a minimum (opens upward) or a maximum (opens downward). Polynomial functions with an odd degree as the highest have relative minimums or maximums at peaks and valleys. Absolute value functions have a vertex that acts as a minimum or maximum.


Domain and Range: The domain is the set of all valid input values (\(x\)-values), and the range is the set of all possible output values (\(y\)-values). Most polynomial functions have a domain of all real numbers, \((-\infty, \infty)\). However, \(f(x) = \sqrt{x}\) is restricted to \(x \geq 0\), and rational functions like \(f(x) = \frac{1}{x}\) exclude values that make the denominator zero.


\(x\)- and \(y\)-Intercepts: The \(x\)-intercept(s) are the points where the graph crosses the \(x\)-axis, found by solving \(f(x) = 0\). The \(y\)-intercept is the point where the graph crosses the \(y\)-axis, found by evaluating \(f(0)\). Some functions have no \(y\)-intercept (if \(x = 0\) is not in the domain) or no \(x\)-intercept (if the function never reaches an output of zero).


Intervals of Increase and Decrease: A function is increasing on an interval when output values grow larger as input values increase (the graph moves upward left to right). A function is decreasing on an interval when output values grow smaller as input values increase (the graph moves downward left to right). We express these intervals using interval notation, such as \((-\infty, 0)\) or \((2, \infty)\). Note that we always use open parentheses at the endpoints of these intervals.

Example: Comparing a Linear and a Quadratic Function with Equations

Compare the following two functions using three key features: average rate of change on \([1, 4]\), \(x\)-intercepts, and end behavior.

\(f(x) = 3x - 6\)    (linear)        \(g(x) = x^2 - 4x + 3\)    (quadratic)

Step 1 — Average Rate of Change (AROC) on \([1, 4]\):

Evaluate each function at the endpoints of the interval, then apply the formula.

For \(f(x) = 3x - 6\):

  • \(\displaystyle \text{AROC} = \frac{6-(-3)}{4-1} = \frac{9}{3} = 3\)

For \(g(x) = x^2 - 4x + 3\):

  • \(\displaystyle \text{AROC} = \frac{3-0}{4-1} = \frac{3}{3} = 1\)

Comparison: On \([1, 4]\), the linear function \(f(x)\) has a higher average rate of change (3) than the quadratic \(g(x)\) (1), so \(f\) is increasing more steeply over this particular interval. The rate of change for a linear function is constant everywhere and equals the slope, while for a quadratic function it varies depending on the chosen interval.


Step 2 — \(x\)-Intercepts:

For \(f(x) = 3x - 6\): Set \(f(x) = 0\):

\(f(x)\) has one \(x\)-intercept at \((2,\, 0)\).

For \(g(x) = x^2 - 4x + 3\): Set \(g(x) = 0\) and factor:

\(g(x)\) has two \(x\)-intercepts at \((1,\, 0)\) and \((3,\, 0)\).

Comparison: A linear function always has exactly one \(x\)-intercept (unless it is horizontal). A quadratic function can have zero, one, or two \(x\)-intercepts because the parabola may cross the \(x\)-axis in two places, touch it at one point (the vertex), or not reach it at all.


Step 3 — End Behavior:

For \(f(x) = 3x - 6\) (linear, positive slope):

  • As \(x \to \infty\),  \(f(x) \to \infty\)
  • As \(x \to -\infty\),  \(f(x) \to -\infty\)
  • Opposite Ends

For \(g(x) = x^2 - 4x + 3\) (quadratic, positive leading coefficient):

  • As \(x \to \infty\),  \(g(x) \to \infty\)
  • As \(x \to -\infty\),  \(g(x) \to \infty\)
  • Both Ends Up

Comparison: Both functions increase without bound as \(x \to \infty\). However, the linear function decreases without bound as \(x \to -\infty\), while the quadratic function also increases without bound on the left. A parabola with a positive leading coefficient always has both ends pointing upward, while a line with a positive slope always goes in opposite directions on each end.

Key Feature \(f(x) = 3x - 6\)  (Linear) \(g(x) = x^2 - 4x + 3\)  (Quadratic)
AROC on \([1, 4]\) 3 (constant slope throughout) 1 (average only; varies by interval)
\(x\)-Intercepts One intercept: \((2,\, 0)\) Two intercepts: \((1,\, 0)\) and \((3,\, 0)\)
End Behavior Opposite ends: one up \(\uparrow\), one down \(\downarrow\) Same ends: both up \(\uparrow\uparrow\)

Example 1

Compare the following two functions using three key features: domain and range, \(x\)- and \(y\)-intercepts, and end behavior.

\(f(x) = 2^x\) and \(g(x) = \log_2(x)\)

Show Answer & Explanation

Domain and Range:

  • \(f(x) = 2^x\): Domain is all real numbers \((-\infty,\, \infty)\). Range is \((0,\, \infty)\) — the output is always positive, never zero or negative.
  • \(g(x) = \log_2(x)\): Domain is \((0,\, \infty)\) — you can only take the logarithm of a positive number. Range is all real numbers \((-\infty,\, \infty)\).
  • Key observation: The domain and range are exactly swapped between the two functions. This makes sense because \(f\) and \(g\) are inverse functions of each other.

\(x\)- and \(y\)-Intercepts:

  • \(f(x) = 2^x\): \(y\)-intercept at \((0, 1)\) since \(2^0 = 1\). There is no \(x\)-intercept because \(2^x > 0\) for all \(x\).
  • \(g(x) = \log_2(x)\): \(x\)-intercept at \((1, 0)\) since \(\log_2(1) = 0\). There is no \(y\)-intercept because \(x = 0\) is not in the domain.
  • Key observation: The intercepts are also swapped, reflecting the inverse relationship. The point \((0, 1)\) on \(f\) corresponds to the point \((1, 0)\) on \(g\).

End Behavior:

  • \(f(x) = 2^x\): As \(x \to \infty\), \(f(x) \to \infty\). As \(x \to -\infty\), \(f(x) \to 0\). The \(x\)-axis is a horizontal asymptote.
  • \(g(x) = \log_2(x)\): As \(x \to \infty\), \(g(x) \to \infty\). As \(x \to 0^+\), \(g(x) \to -\infty\). The \(y\)-axis is a vertical asymptote.
  • Comparison: Both functions grow without bound to the right, but exponential growth is much faster than logarithmic growth. The exponential function levels off toward zero on the left, while the logarithm plunges to \(-\infty\) near its vertical asymptote.

Example 3

The function \(f\) is defined by the equation \(f(x) = 2x - 4\).
The graph of \(g\) is shown below.

Compare the two functions using three key features: \(x\)- and \(y\)-intercepts, end behavior, and domain.

Show Answer & Explanation

\(x\)- and \(y\)-Intercepts:

  • \(f(x) = 2x - 4\): Set \(f(x) = 0\) to find the \(x\)-intercept: \(2x - 4 = 0 \Rightarrow x = 2\), giving one \(x\)-intercept at \((2,\, 0)\). Evaluate \(f(0) = 2(0) - 4 = -4\), giving a \(y\)-intercept at \((0,\, -4)\).
  • \(g(x)\): From the graph, the curve crosses the \(x\)-axis at \((1,\, 0)\) and \((3,\, 0)\) — two \(x\)-intercepts. The curve meets the \(y\)-axis at \((0,\, 1)\) — the \(y\)-intercept.
  • Comparison: \(f\) has one \(x\)-intercept while \(g\) has two. A linear function can cross the \(x\)-axis at most once. An absolute value function can cross the \(x\)-axis zero, one, or two times depending on the position of its vertex. Additionally, \(f\) has a negative \(y\)-intercept at \((0, -4)\) while \(g\) has a positive \(y\)-intercept at \((0, 1)\), so they cross the \(y\)-axis on opposite sides.

End Behavior:

  • \(f(x) = 2x - 4\): The leading coefficient is positive, so as \(x \to \infty\), \(f(x) \to \infty\) and as \(x \to -\infty\), \(f(x) \to -\infty\). The two ends go in opposite directions.
  • \(g\): From the graph, both arms of the V-shape point upward and continue rising as they extend outward in each direction. As \(x \to \infty\), \(g(x) \to \infty\) and as \(x \to -\infty\), \(g(x) \to \infty\). Both ends go in the same direction — upward.
  • Comparison: This is a key structural difference. The linear function has ends going in opposite directions — one rising, one falling — because it is a straight line with a nonzero slope. The absolute value function has both ends rising because it is V-shaped and opens upward.

Domain:

  • \(f(x) = 2x - 4\): Any real number can be substituted for \(x\) in a linear equation. Domain is all real numbers \((-\infty,\, \infty)\).
  • \(g\): From the graph, the curve extends to the left and right without any breaks, holes, or endpoints. There are no restrictions on the input values. Domain is all real numbers \((-\infty,\, \infty)\).
  • Comparison: Both functions have the same domain — all real numbers. Neither has any restrictions, gaps, or asymptotes. This is one feature where the two functions are identical, despite their very different shapes and behaviors.



Conclusion

In this lesson, you explored how to compare key features of different types of functions, including average rate of change on a given interval, end behavior, maximums and minimums, domain and range, intercepts, and intervals of increase and decrease. Each function family carries its own signature characteristics — linear functions have a constant rate of change, quadratic functions have a single vertex, exponential functions approach an asymptote on one end, rational functions may have gaps in their domain, and so on. When you compare two functions side by side, you move beyond simply knowing the rules for each type and begin to see deeper mathematical relationships. The inverse connection between exponential and logarithmic functions, the domain contrast between square root and cube root functions, and the strikingly different end behaviors of absolute value and rational functions are all examples of insights that only emerge through comparison. As you continue in this course, these comparison skills will help you interpret graphs, solve real-world problems, and connect ideas across function families. Keep practicing — understanding why functions behave the way they do is just as important as knowing how to calculate their values.
