📚 VOCABULARY

Absolute Value Function: A function that contains an absolute value expression and produces a V-shaped graph, typically written in the form \(f(x)=a|x-h|+k\).

Constant Ratio: The fixed number by which consecutive terms in a geometric sequence or exponential pattern are multiplied.

Cube Root Function: A function written in the form \(f(x)=a\sqrt[3]{x-h}+k\), whose graph has an S-shaped curve and extends infinitely in both directions.

Cubic Function: A polynomial function of degree three, typically written in the form \(f(x)=ax^3+bx^2+cx+d\), whose graph may have one or two turning points.

Exponential Decay: A type of exponential function in which values decrease by a constant percent rate, occurring when the base is between 0 and 1.

Exponential Growth: A type of exponential function in which values increase by a constant percent rate, occurring when the base is greater than 1.

Exponential Function: A function written in the form \(f(x)=ab^x\), where the variable is in the exponent and the base is a positive constant not equal to 1.

First Differences: The differences found by subtracting consecutive output values in a table, used to determine whether a function is linear.

Function: A relation in which each input corresponds to exactly one output.

Input-Output Table: A table that lists input values and their corresponding output values to represent a function.

Linear Function: A function written in the form \(f(x)=mx+b\), whose graph is a straight line with a constant rate of change.

Quadratic Function: A polynomial function of degree two, typically written in the form \(f(x)=ax^2+bx+c\), whose graph forms a parabola.

Second Differences: The differences found by subtracting consecutive first differences in a table, used to determine whether a function is quadratic.

Square Root Function: A function written in the form \(f(x)=a\sqrt{x-h}+k\), whose graph begins at a starting point and increases or decreases gradually.

💡 EXPLORING THE MATH

In Algebra 2, functions can be represented in many different ways, including equations, graphs, and tables. When you are given an input-output table, your goal is to look for patterns in how the outputs change as the inputs increase. These patterns help you determine whether the function is linear, quadratic, exponential, cubic, square root, cube root, or absolute value. In this lesson, you will learn specific strategies for analyzing tables so you can confidently identify the function type.

Analyzing a Table of Values for Function Type

When working with a table, follow these steps:

  1. Check how the x-values change. (Usually they increase by 1.)

  2. Look at how the y-values change.

  3. Decide whether the pattern is additive (adding/subtracting), multiplicative (multiplying), or something else.

Below are the key patterns for each function type.

Linear Function

A linear function has a constant rate of change.

Look for:
• Constant first differences (subtract consecutive y-values).

If the first differences are the same number each time, the function is linear.

Example:
Quadratic Function

A quadratic function does not have constant first differences, but it does have constant second differences.

The table might have symmetry in the y-values.

Steps:

  1. Find first differences.

  2. Find differences of those first differences (second differences).

  3. If the second differences are constant, the function is quadratic.

Example:
Cubic Function A cubic function has:
• Non-constant first differences
• Non-constant second differences
• Constant third differences

Example:
Exponential Function

An exponential function has a constant ratio between outputs.

Instead of subtracting, divide consecutive y-values.

If the ratio is constant, the function is exponential.

Example:
Square Root Function

A square root function shows:

  • X-values increase by consecutive odd numbers.
  • Y-values increase by increments of 1.

Example:
Cube Root Function A cube root function:
• May include negative and positive values
• Has increasing differences of 1 for the y-values.
• X-values will be oppositely symmetrical and increase or decrease rapidly on the sides of that symmetry.

Example:
Absolute Value Function An absolute value function:
• Has symmetry in the table
• Y-values decrease to a minimum, then increase
• Equal distances from the center produce equal outputs

Example:

 

Example 1

Given the table:

x y
-3 -1
0 -2
3 -3
6 -4

What type of function is represented?

A. Quadratic
B. Linear
C. Exponential
D. Absolute Value

Solution:

We see that the 1st difference in the y-values is -1.

We also notice that the y-values increase in a constant value as well by 3.

This makes this table represent a linear function.

Answer: B



Example 2

Given the table:

x y
-2 13
-1 7
0 5
1 7
2 13
3 23

What type of function is represented?

A. Cube Root
B. Absolute Value
C. Exponential
D. Quadratic

Solution:

We see there is symmetry on either side of the point (0,5).

If we find the 2nd difference, it is a constant of +4.

  • 1st difference

  • 2nd difference

This makes this table represent a Quadratic Function.

Answer: D



Example 3

Given the table:

x y
0 2
1 6
2 18
3 54

What type of function is represented?

A. Cube Root
B. Absolute Value
C. Exponential
D. Quadratic

Solution:

We see that the y-values increase rapidly as the table goes on.

The 1st and 2nd differences do not become constants.

If we look at the ratio of consecutive y-values, they are all 3.

This makes this table represent an Exponential Function.

Answer: C



Conclusion

Identifying function types from input-output tables requires careful observation of patterns. Linear functions have constant first differences, quadratic functions have constant second differences, and cubic functions have constant third differences. Exponential functions have a constant ratio. Absolute value functions show symmetry, and square root or cube root functions show gradual, non-constant change patterns. By consistently checking differences, ratios, and symmetry, you can confidently determine the function type represented in any table of values.
