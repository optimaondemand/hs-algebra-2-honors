📚 VOCABULARY

Asymptote: A line that a graph approaches but never reaches, describing the long-term behavior of a function.

Base: The positive number in an exponential or logarithmic function that determines the rate of growth or the scale of the function.

Domain: The set of all possible input values for which a function is defined.

Logarithmic Function: A function that expresses the inverse relationship of an exponential function and answers the question of what exponent produces a given value.

Range: The set of all possible output values of a function.

Vertical Asymptote: A vertical line that a graph approaches but never crosses, often indicating a restriction in the domain of the function.

Y-Intercept: The point where a graph crosses the y-axis, representing the value of the function when the input is zero.

💡 EXPLORING THE MATH

Logarithmic functions are the inverse of exponential functions and are used to describe situations where growth happens quickly at first and then slows over time. Before working with transformations or more complex models, it is important to understand the basic structure and behavior of a logarithmic function. In this lesson, you will learn how to identify the structure of a basic logarithmic function and interpret its graph by identifying key features such as the x-intercept, vertical asymptote, domain, and range. You will also learn how these features are interpreted when logarithmic functions are used to model real-world situations.
