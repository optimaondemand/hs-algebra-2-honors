📚 VOCABULARY

Asymptote: A line that a graph approaches but never reaches, often describing the long-term behavior of a function.

Base: The constant value in an exponential function that is repeatedly multiplied and determines whether the function represents growth or decay.

Compounded Interest: Interest calculated on the initial amount of money and also on the accumulated interest from previous periods.

Continuous Growth: A type of growth that occurs constantly over time and is modeled using an exponential function with base e.

Continuously Compounded Interest: Interest that is added an infinite number of times per year, resulting in growth modeled by an exponential function with base e.

Domain: The set of all possible input values for which a function is defined.

Exponential Function: A function in which the independent variable appears in the exponent and represents growth or decay at a constant percent rate.

Growth Factor: The factor by which a quantity is multiplied in each unit of time in an exponential function, often written as \(1+r\).

Initial Value: The starting value of a function, typically the value of the function when the input is zero.

Natural Base (e): An irrational number approximately equal to 2.718 that is used as the base of exponential functions modeling continuous growth or decay.

Percent Rate of Change: The constant percentage by which a quantity increases or decreases over a given time interval in an exponential function.

Range: The set of all possible output values of a function.

Rate of Growth: The amount by which a quantity increases relative to its current value over a given time period, expressed as a decimal or percentage.

Y-Intercept: The point where a graph intersects the y-axis, representing the value of the function when the input is zero.

💡 EXPLORING THE MATH

Exponential functions are powerful tools for modeling situations where quantities grow or decrease by a constant percent over time. These functions appear frequently in real-world contexts such as population growth, bacteria growth, depreciation, and especially finance through interest models. In this lesson, you will learn how exponential functions are structured, how to identify and interpret their rates of growth, how to analyze their graphs, and how to apply them to real-world situations involving compound and continuously compounded interest. By the end of this lesson, you will be able to read, interpret, and compare exponential models both algebraically and graphically.

Structure of an Exponential Function

An exponential function with a real-number base is typically written in the form

Each part of this function has a specific meaning:

  • a is the initial value. It represents the starting amount when \(x=0\).

  • b is the base. It determines whether the function represents growth or decay.

    • If \(b>1\), the function represents exponential growth.

    • If \(0<b<1\), the function represents exponential decay.

  • x is the independent variable, often representing time.

The percent rate of growth comes from the base.

If \(b=1+r\), then \(r\) is the growth rate written as a decimal.

If \(b=1-r\), then \(r\) is the decay rate written as a decimal.

Determining the Constant Percent Rate of Change

Exponential functions change by a constant percent, not a constant amount. The percent rate of change can be found from:

  • An equation

  • An expression

  • A table of values

If the function is written in the form \(f(x)=a(b)^x\), the percent rate of change is found by converting the base \(b\) to a percentage.

From a table, you can find the growth factor by dividing consecutive output values or the y-values.

The initial value in a table is the y-value where \(x=0\).


Example

For the given function, find the percent rate of change and the initial value.

\(f(x)=500(1.12)^x\)

The base is 1.12, so the percent rate of change is 12% growth.

The initial value is 500.

Interpreting Graphs and Key Features of Exponential Functions

Exponential Function

\(\Large f(x)=a(b)^x\)

\(\Large f(x)=a(e)^x\)

Graphs of exponential functions have consistent key features:

  • Y-intercept: The value of the function when \(x=0\), which is the initial value \(a\), written as \((0,a)\).

  • Horizontal asymptote: A line that the graph approaches but never touches.

    • For basic exponential growth and decay, this is usually \(y=0\).

  • Domain: All real numbers.

  • Range: All positive numbers if \(a>0\).

  • End Behavior:
    • For exponential growth:
      • as \(x\) approaches \(-\infty \), \(y\) approaches \(0\) due to the horizontal asympotote;
      • as \(x\) approaches \(\infty\), \(y\) approaches \(\infty\) since the graph is growing to the right.;
    • For exponential decay:
      • as \(x\) approaches \(-\infty \), \(y\) approaches \(\infty\) since the graph is growing to the left;
      • as \(x\) approaches \(\infty \), \(y\) approaches \(0\) due to the horizontal asymptote;
    • If the horizontal asymptote changes, then what y approaches will change for one of the end behaviors.

  • Constraints: Restrictions based on the real-world situation (for example, time cannot be negative).

  • Exponential Growth: when the graph grows from left to right.
  • Exponential Decay: when the graph decreases from left to right.

This also tells us that the base is between 0 and 1.

Compounding Interest Formulas

Compound interest is calculated using the formula:

  • P is the principal (initial amount)

  • r is the annual interest rate

  • n is the number of times interest is compounded per year

  • t is time in years


Continuously compounded interest uses the formula:

  • P is the principal (initial amount)

  • r is the annual interest rate

  • t is time in years

Both formulas are exponential and model growth, but continuous compounding grows slightly faster over time because interest is added constantly.

Conclusion

Exponential functions are essential for understanding situations that involve constant percent change. By learning how to identify the structure of an exponential function, determine its growth rate, interpret its graph, and apply it to real-world contexts like interest, you gain powerful tools for mathematical modeling. Understanding the differences between compound and continuously compounded interest also helps you make informed financial decisions. With practice, exponential functions become a clear and effective way to describe growth and change over time.
