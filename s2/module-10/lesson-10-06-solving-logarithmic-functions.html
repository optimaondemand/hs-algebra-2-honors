📚 VOCABULARY

Approximate Solution: A value that is close to the exact answer and is often found using graphs, tables, or estimation when an exact solution is difficult or impractical to determine.

Domain: The set of all possible input values for which a function is defined.

Exponential Function: A function in which the independent variable appears in the exponent and models growth or decay at a constant percent rate.

Inverse Functions: Two functions that undo each other, meaning applying one after the other returns the original input value.

Logarithmic Function: A function that is the inverse of an exponential function and expresses the exponent needed to produce a given value from a given base.

Natural Log: A logarithmic function with base e, written as \(\ln{x}\), commonly used to model continuous growth and decay.

Range: The set of all possible output values of a function.

💡 EXPLORING THE MATH

Logarithmic and natural logarithmic functions are used to solve problems where quantities grow or change at varying rates. These functions commonly appear in science, finance, and real-world modeling situations such as population growth, sound intensity, and radioactive decay. In this lesson, you will learn how to evaluate logarithmic and natural log functions when given an input value and how to solve for an unknown input when given an output value. You will also practice interpreting solutions in context and deciding when exact or approximate answers are appropriate.

Evaluating Logarithmic or Natural Log Functions Given x

When solving a logarithmic or natural logarithmic function for a given x, you are evaluating the function to find the corresponding y-value.

Common forms:

\(\Large f(x)=\log_{b}{(x)}\)

\(\Large f(x)=\ln{(x)}\)

  • Exact values are possible when the argument is a power of the base.

  • Approximate values are used when the argument is not a convenient power.


When finding y or the value of the function, f(x), for a given x value, substitute the x value in and evaluate using the order of operations.


Examples:

Find \(f(8)\) for the given function.

\(f(x)=\log_{2}{(x)}\)

Solution:

Substitute the value 8 in for x into the function and evaluate.

Evaluating can sometimes produce approximate answers. If the evaluation creates a non-terminating decimal, then leaving in log form is the exact answer.

Answer: \(f(8)=3\)


Exact values are possible when the argument is a power of the base. Otherwise, approximate values are used.


Find \(f(3)\) for the given function.

\(f(x)=\ln{(x+2)}\)

Solution:

We will substitute 3 in for x.

\(f(3)=\ln{(3+2)}\).

We can simplify inside the parentheses to get \(f(3)=\ln{(5)}\).

For the next step, we would have to use a calculator to get an approximate answer.

Answer:

Exact Answer is \(f(3)=\ln{(5)}\)

Approximate Answer rounded to the nearest hundredth is 1.61.

Example 1

Given the function.

\(f(x)=3\log_{5}{(x)}\)

Evaluate \(f(25)\).

Solution:

We will begin by substituting 25 in for x and evaluating using the order of operations.

The log function goes up at the beginning of the order with exponents since they are inverse operations.

So, we would calculate anything inside a parenthesis first. Then we would evaluate logs or exponents next. Then multiplication and division to follow that. Any outside addition and subtraction would come last.

  • Remember that logs are inverses of exponents. To evaluate a log, we ask ourselves, the base to what power would create the argument.
  • For this problem, 5 to what power would make 25? The answer would be 2.
  • This works when there is an exact answer. Otherwise, we would use a calculator to find an approximation.
  • So, \(\log_{5}{(25)}\) is the value 2.
  • Now, we evaluate the multiplication.

Answer: \(f(25)=6\)

Solving Logarithmic and Natural Log Functions Given y

When solving for an unknown input, isolate the logarithmic expression first, then rewrite the equation in exponential form.

General rules:

First isolate the logarithm, then convert to exponential form.


Examples:

Given the function.

Solve for x, given \(f(x)=2\).

Solution:

Begin by setting the function equal to 2.

The log is already isolated. So, we will convert to exponential form.

Now, we can evaluate the exponential expression and solve for x.

Answer: \(x=10\)


Given the function.

\(f(x)=2\ln{(x)}-5 \)

Solve for x when \(f(x)=3\).

Solution:

Begin by setting the function equal to 3.

We need to isolate the log first.

Now, we will convert to exponential form using base e.

The exact answer is \(e^4\).

We can approximate the answer using a calculator; \(x=e^4 \approx 54.59815...\)

Answer: \(x=e^4 \approx 54.598\)

Example 1

Given the function.

\(f(x)=\log_{4}{(x-3)}\).

Find the value of x when \(f(x)=1\).

Solution:

We will begin by setting the equation equal to 1.

The log is isolated since there are no numbers on the outside. So, we will convert to exponential form.

Now, we can isolate the x.

Answer: \(x=7\)



Example 2

Given the function.

\(f(x)=\ln{(x-2)}+4\).

Find the value of x when \(f(x)=6\).

Solution:

We will begin by setting the equation equal to 6.

We will next isolate the log by subtracting 4 from both sides.

Now, we will convert to exponential form using base e.

Now, we can isolate the x.

The exact answer is \(e^2+2\). We can approximate it using a calculator.

Answer: \(x=e^2+2 \approx 9.389\)

 

Real-World Logarithmic Functions

In real-world situations, logarithmic functions often include constants and coefficients. Solutions are expressed as approximations, and interpreting the solution means explaining what the value represents in context.

Example 1

The acidity of a solution is modeled by the given function.

Evaluate the \(pH\) when \(C=0.01\).

Solution:

Begin by substituting the value of C into the function.

Now, we can use a calculator to evaluate the expression.

We find that \(pH=3\).

Answer: The acidity of the solution will be 3.



Example 2

The given function models a chemical concentration.

Approximately how long will it take for the chemical concentration to reach 2.

Solution:

Begin by setting the equation equal to 2.

We will first isolate the log by adding 1 to both sides.

Convert the equation to an exponential using base e.

Now, we can use a calculator to evaluate the expression.

We find that \(t\approx 20.09\).

Answer: The chemical concentration will reach 2 in approximately 20.1 minutes.



Conclusion

Logarithmic and natural logarithmic functions often appear in forms that include coefficients and added or subtracted constants. By learning how to evaluate these functions for a given input and solve for an unknown input using exponential form, you can handle both mathematical and real-world problems with confidence. Understanding when to give exact solutions and when to approximate, and interpreting solutions in context, helps connect logarithmic functions to meaningful applications beyond the classroom.
