📚 VOCABULARY

Asymptote: A line that a graph approaches but never reaches, often showing the long-term behavior of a function.

Base: The constant value in an exponential function that is repeatedly multiplied and determines whether the function represents growth or decay.

Compounded Interest: Interest calculated on the initial amount of money and on the accumulated interest from previous compounding periods.

Continuously Compounded Interest: Interest that is added an infinite number of times per year, resulting in growth modeled by an exponential function with base e.

Domain: The set of all possible input values for which a function is defined.

Exponential Function: A function in which the variable appears in the exponent and represents growth or decay at a constant percent rate.

Function Notation: A way to represent a function using symbols, typically written as \(f(x)\), where \(x\) is the input and \(f(x)\) is the output.

Horizontal Shift: A transformation that moves a graph left or right along the x-axis.

Initial Value: The starting value of a function, usually the output when the input is zero.

Percent Rate of Change: The constant percentage by which a quantity increases or decreases for each unit change in the independent variable.

Range: The set of all possible output values of a function.

Rate of Growth: The amount by which a quantity increases relative to its current value over a given time interval, expressed as a decimal or percentage.

Reflection: A transformation that flips a graph over a line, such as the x-axis or y-axis.

Transformation: A change made to a graph that alters its position, shape, or orientation.

Translation: A transformation that slides a graph without changing its shape.

Vertical Shift: A transformation that moves a graph up or down along the y-axis.

Y-Intercept: The point where a graph crosses the y-axis, representing the value of the function when the input is zero.

💡 EXPLORING THE MATH

Transformations allow us to understand how changing an equation affects the appearance and meaning of a graph. In Algebra 2, translations are especially important when working with exponential functions because they help model real-world situations such as starting values, delays, and shifts in time. In this lesson, you will learn how vertical and horizontal translations change a graph, how key features are affected, how to identify transformations from equations, tables, and graphs, and how to write equations or tables that represent transformed functions.

Effects of Vertical Translations

Transformation function:

A translation moves a graph without changing its shape. There are two types of translations covered in this lesson:

  • Vertical translations:

    • Form: \(f(x)+k\)

    • If \(k>0\), the graph moves up.

    • If \(k<0\), the graph moves down.

Translations affect the key features of a graph:

  • Y-intercept: Changes with vertical shifts

  • Horizontal asymptote: Will shift with the vertical translation

  • End behavior: Remains the same shape, but will approach a different value than 0.

  • Domain: Will remain all real numbers

  • Range: Changes with vertical shifts


Example

Given the base function \(f(x)=2^x\), consider the transformed function \(g(x)=2^x+3\).

Identify the key features of the transformed function.

This is a vertical translation up 3 units.

  • New y-intercept: \((0,4)\)

    • Calculated by substituting 0 for x;

  • New asymptote: \(y=3\)

    • The base horizontal asypmtote is \(y=0\). Since the function is translated up 3 units, the horizontal asymptote is also translated up 3 units.

  • New End Behavior:

    • as \(x\rightarrow -\infty\), then \(y\rightarrow 3\) and as \(x\rightarrow \infty\), then \(y\rightarrow \infty\)
      The end behavior is affected by the horizontal asymptote as far as what it approaches as it decreases.

  • Domain: all real numbers \(-\infty < x < \infty\)

  • Range: \(y>3\)

    • The range is affected by the placement of the horizontal asymptote. It either grows from the HA or decays towards the HA.

Example 1

The function \(g(x)=(\frac{1}{4})^x-2\) represents a transformation of the base function \(f(x)=(\frac{1}{4})^x\), as shown in the graph.

Identify the transformation and the key features of \(g(x)\).

Solution:

The graph was shifted down 2 units. We see that the y-intercept of the parent function is at \((0,1)\) and it is at \((0,-1)\) for the transformed function.

We can identify the y-intercept from the graph by looking at where it crosses the y-axis.

  • y-intercept \((0,-1)\)

Since this is a vertical transformation, the horizontal asymptote is shifted down by 2 units.

  • Horizontal Asymptote: \(y=-2\)

Since this is exponential decay, the end behavior for when x approaches \(\infty\) is affected by the vertical translation as it approaches the horizontal asymptote.

  • as \(x\rightarrow -\infty\), then \(y\rightarrow \infty \)
  • as \(x\rightarrow \infty\), then \(y\rightarrow -1\)

The domain is unaffected by transformations since it is all real numbers.

  • D= \(-\infty < x < \infty\)

The range is affected by vertical translations that change the asymptote.

  • R= \(y > -1\)

Effects of Horizontal Translations

Transformation function:

A translation moves a graph without changing its shape. There are two types of translations covered in this lesson:

  • Horizontal translations:

    • Form: \(f(x-h)\)

    • If \(h>0\), the graph moves left.

    • If \(h<0\), the graph moves right.

Translations affect the key features of a graph:

  • Y-intercept: Changes with horizontal shifts

  • Horizontal asymptote: Will not change

  • End behavior: Remains the same shape

  • Domain: Will remain all real numbers

  • Range: Will remain \(y>0\)


Example

Given the base function \(f(x)=e^x\), consider the transformed function \(g(x)=e^{(x+2)}\).

Identify the key features of the transformed function.

This is a horizontal translation left 2 units. 
Look for the y-intercept of the parent function and check its movement in comparison with other points. The y-intercept is higher in the transformed function, but if you compare the upward movement, it is not consistent with other points.
We compare the movement of points left, and we notice they all moved 2 units left.

  • New y-intercept: \((0,e^2)\)

    • Calculated by substituting 0 for x;

  • Asymptote remains the same as \(y=0\)

  • End Behavior remains the same

    • as \(x\rightarrow -\infty\), then \(y\rightarrow 0\) and as \(x\rightarrow \infty\), then \(y\rightarrow \infty\)

  • Domain: all real numbers \(-\infty < x < \infty\)

  • Range: \(y>0\)

Example 1

The function \(g(x)=3^{(x-5)}\) represents a transformation of the base function \(f(x)=3^x\).

Identify the transformation and the key features of \(g(x)\).

Solution:

The graph will shift right 5 units.

We can calculate the y-intercept by substituting 0 in for x.

  • y-intercept \((0,\frac{1}{243})\)

Since this is a horizontal transformation, the horizontal asymptote is unaffected.

  • Horizontal Asymptote: \(y=0\)

The end behavior is unaffected by horizontal translations since it will still increase or decrease towards the horizontal asymptote, which is unaffected.

  • as \(x\rightarrow -\infty\), then \(y\rightarrow 0\)
  • as \(x\rightarrow \infty\), then \(y\rightarrow \infty\)

The domain is unaffected by transformations since it is all real numbers.

  • D= \(-\infty < x < \infty\)

The range is affected by vertical translations that change the asymptote.

  • R= \(y > 0\)

 

 

Identifying the Type and Value of Translation

To identify a translation, compare the original function \(f(x)\) to the transformed function.

  • \(f(x)+k\) → vertical shift

  • \(f(x+h)\) → horizontal shift (opposite direction of the sign)

To write an equation:

  • Vertical shift → add k outside the function

  • Horizontal shift → add h inside the function

To create a table:

  • Vertical shift → add k to each output value

  • Horizontal shift → add h to each input value


Example

The parent function \(f(x)=2^x\) is translated down 4 units using the transformation function \(f(x)-4\).

The equation of the transformation function will be \(g(x)=2^x-4\).

Conclusion

Understanding vertical and horizontal translations allows you to predict and explain how exponential graphs change without altering their overall shape. By analyzing equations, tables, and graphs, you can identify the type and size of a translation, determine how key features are affected, and create new representations of transformed functions. These skills are essential for interpreting mathematical models and real-world situations where changes over time are shifted or adjusted. With practice, recognizing and applying translations becomes a powerful tool in Algebra 2.
