📚 VOCABULARY

Asymptote: A line that a graph approaches but never reaches, indicating the long-term behavior of a function.

Domain: The set of all possible input values for which a function is defined.

Horizontal Shift: A transformation that moves a graph left or right along the x-axis without changing its shape.

Logarithmic Function: A function that is the inverse of an exponential function and expresses the exponent needed to produce a given value from a specified base.

Range: The set of all possible output values of a function.

Reflection: A transformation that flips a graph across a line, such as the x-axis or y-axis.

Transformation: A change made to a graph that alters its position, orientation, or size.

Translation: A transformation that slides a graph horizontally or vertically without changing its shape.

Vertical Asymptote: A vertical line that a graph approaches but never crosses, often representing a restriction in the domain.

Vertical Shift: A transformation that moves a graph up or down along the y-axis without changing its shape.

💡 EXPLORING THE MATH

Once you understand the basic structure and graph of a logarithmic function, the next step is learning how transformations affect its graph and equation. Transformations allow logarithmic functions to model real-world situations more accurately by shifting or reflecting the graph while preserving its overall shape. In this lesson, you will learn how reflections, vertical translations, and horizontal translations affect logarithmic functions. You will also learn how to identify transformations from equations, graphs, and tables, and how to create new equations or tables based on a given transformation.

Parent Logarithmic Function

Common Logarithm

\(\Large f(x)=\log{x}\)

Note, the base of the parent function is 10, a common log. So, we do not write the base.

Key features of the parent function:

  • Vertical asymptote: \(x=0\)

  • Domain: \(x>0\)

  • Range: all real numbers,

  • X-intercept: \((1,0)\)

  • No y-intercept

Natural Logarithm

\(\Large f(x)=\ln{x}\)

Note, the base of a natural log is e.

Key features of the parent function:

  • Vertical asymptote: \(x=0\)

  • Domain: \(x>0\)

  • Range: all real numbers,

  • X-intercept: \((1,0)\)

  • No y-intercept

All transformations discussed in this lesson start from this parent function unless otherwise stated.

 

Vertical Translations

Transformation Function:

Parent Function: \(f(x)=\log{(x)}\)

Transformation Function: \(g(x)=\log{(x+h)}+k\)

A vertical translation moves the graph up or down without changing its shape.

The transformed function is written as:

\(g(x)=f(x)+k\)

  • If \(k>0\), the graph shifts up

  • If \(k<0\), the graph shifts down

Effects on key features:

  • The vertical asymptote stays the same

  • The domain stays the same

  • The range shifts up or down

  • The x-intercept may change


To identify if a graph of a logarithmic function has shifted up or down, check the first point against the x-intercept of the parent function.


Example:

The graph of the parent function \(f(x)=\log{(x)}\) and a transformed function are shown in the graph.

Identify the transformation and value of k. Which key features were affected?

Solution:

If we notice the x-intercept of \((1,0)\) in the parent function and what happened to it for the transformed function, we will notice it shifted up 2 units.

The graph shifted up 2 units.

This makes the equation of the transformed function \(g(x)=\log{(x)}+2\).

Only the x-intercept will be affected by this transformation.


Note

The parent function can be

  • a log with a base where b>1, \(\log_{b}{x}\)
  • a common log with base 10, \(\log{x}\)
  • or a natural log with base e, \(\ln{x}\)

Example 1

Given the transformed equation \(g(x)=\log{(x)}-3\) of the parent function \(f(x)=\log{(x)}\), identify the following.

  • Type of transformation
  • Value of the shift
  • Key features affected

Solution:

We see that 3 was subtracted from the whole function, which aligns with \(f(x)-3\). Since the value of k is less than 0, this tells us that this is a shift of 3 units down.

  • Transformation is a vertical shift down.
  • Value of shift is down 3 units.
  • Only the x-intercept is affected.



Example 2

Given the parent function \(f(x)=\ln{(x)}\) and a transformation as shown in the graph, identify the following.

  • Type of transformation
  • Value of the shift
  • Key features affected

Solution:

Notice that the x-intercept of \((1,0)\) of the parent function has moved up 5 units.

  • Transformation is a vertical shift up.
  • Value of shift is up 5 units.
  • Only the x-intercept is affected.

 

Horizontal Translations

A horizontal translation moves the graph left or right.

The transformed function is written as:

\(\Large g(x)=f(x+h)\)

  • If \(h>0\), the graph shifts left

  • If \(h<0\), the graph shifts right

Effects on key features:

  • The vertical asymptote shifts left or right, to be the value of the horizontal translation

  • The domain changes based on the value of the horizontal shift

  • The range stays the same

  • The x-intercept also shifts left or right, to be 1 plus the value of the horizontal translation

  • The existence of a y-intercept is affected only by shifts to the left.


To identify if a graph of a logarithmic function has shifted up or down, check the first point against the x-intercept of the parent function.


Example:

The graph of the parent function \(f(x)=\log_{3}{(x)}\) and a transformed function are shown in the graph.

Identify the transformation and value of the transformation. Which key features were affected?

Solution:

If we notice the x-intercept of \((1,0)\) in the parent function and what happened to it for the transformed function, we will notice it shifted right 3 units.

The graph shifted right 3 units.

This makes the equation of the transformed function \(g(x)=\log{(x-3)}\).

The vertical asymptote shifted right 3 units and became \(x=3\).

The x-intercept shifted right 3 units and became \((4,0)\).

The domain shifted with the asymptote and is now \(x>3\).

The range remains the same, and there is still no y-intercept.

Note

The parent function can be

  • a log with a base where b>1, \(\log_{b}{x}\)
  • a common log with base 10, \(\log{x}\)
  • or a natural log with base e, \(\ln{x}\)

Example 1

Given the parent function \(f(x)=\log{(x)}\) and a transformation as shown in the graph, identify the following.

  • Type of transformation
  • Value of the shift
  • Key features affected

Solution:

Notice that the x-intercept of \((1,0)\) of the parent function has moved left 4 units.

  • Transformation is a horizontal shift left for the transformed function \(f(x+4)\).
  • Value of shift is left 4 units.
  • The Asymptote is shifted left 4 units to \(x=-4\).
  • The x-intercept is shifted left 4 units to \((-3,0)\).
  • The domain is now \(x>-4\).
  • There is also a y-intercept now where there was not one before.



Example 2

Given the transformed equation \(g(x)=\log_{4}{(x-6)}\) of the parent function \(f(x)=\log_{4}{(x)}\), identify the following.

  • Type of transformation
  • Value of the shift
  • Key features affected

Solution:

We see that 6 was subtracted from the x inside the function, which aligns with \(f(x-h)\). Since the value of h is greater than 0, this tells us that this is a shift of 6 units right.
Left and right shifts are always the opposite of what they are in the function.

  • Transformation is a horizontal shift to the right.
  • Value of shift is right 6 units.
  • The asymptote will shift right 6 units to \(x=6\).
  • The x-intercept will shift right 6 units to \((7,0)\).
  • The domain is now \(x>6\).

 

Identifying the Type and Value of Translation

To identify a translation, compare the original function \(f(x)\) to the transformed function.

  • \(f(x)+k\) → vertical shift

  • \(f(x+h)\) → horizontal shift (opposite direction of the sign)

To write an equation:

  • Vertical shift → add or subtract k outside the function

  • Horizontal shift → add or subtract h inside the function

To create a table:

  • Vertical shift → add or subtract k to each output value

  • Horizontal shift → add or subtract h to each input value


Example

The parent function \(f(x)=2^x\) is translated using the transformation function \(f(x)-4\).

The graph will be translated down 4 units.

Example 1

A vertical shift of 3 units up is applied to the parent function \(f(x)=\log_{5}{(x)}\).

Which function represents the transformed function?

A.

B.

C.

D.

Solution:

Since the transformation is a shift up 3 units, the transformation is applied to the whole function, \(f(x)\).

This will make the equation \(g(x)=\log_{5}{(x)}+3\).

Answer: C



Example 2

A horizontal shift of left 5 units is applied to the parent function \(f(x)=\ln{(x)}\).

Which function represents the transformed function?

A.

B.

C.

D.

Solution:

Since the transformation is a shift left 5 units, the transformation is applied to the whole function, \(f(x+5)\).

This will make the equation \(g(x)=\ln{(x+5)}\).

Answer: A



Example 3

A horizontal shift of 2 units left is applied to the parent function \(f(x)=\log_{2}{x}\). The table of values for the parent function is given.

x f(x)
1 0
2 1
4 2
8 3

What would the table of values for the transformation function be?

Solution:

Since we are shifting left 2 units, we subtract 2 from all the x values in the table, and the y values remain the same.

x g(x)
1-2=-1 0
2-2=0 1
4-2=2 2
8-2=6 3

Answer: 

x g(x)
-1 0
0 1
2 2
6 3



Example 4

A vertical shift of 6 units down is applied to the parent function \(f(x)=\log_{3}{x}\). The table of values for the parent function is given.

x f(x)
1 0
3 1
9 2

What would the table of values for the transformation function be?

Solution:

Since we are shifting down 6 units, we subtract 6 from all the y values in the table, and the x values remain the same.

x g(x)
1 0-6=-6
3 1-6=-5
9 2-6=-4

Answer: 

x g(x)
1 -6
3 -5
9 -4



Conclusion

Transformations allow logarithmic functions to be adjusted while preserving their overall shape and behavior. By understanding reflections, vertical translations, and horizontal translations, you can identify how a logarithmic graph has changed and explain those changes using equations, graphs, or tables. Being able to create new representations from a given transformation strengthens your ability to model real-world situations and prepares you for more advanced logarithmic applications.
