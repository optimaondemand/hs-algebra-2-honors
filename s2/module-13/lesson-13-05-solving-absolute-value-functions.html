📚 VOCABULARY

Constraint: A restriction on the domain or range of a function based on the limits of a real-world context, such as time or quantity not being allowed to take negative values.

Domain: The set of all allowable input values (\(x\)-values) for a function; in a real-world context, the domain is often restricted to values that are physically or logically meaningful.

Evaluate: To substitute a specific value for the input variable of a function and calculate the corresponding output; written as finding \( f(a) \) for a given value \( a \).

Function Notation: A way of expressing a function using the form \( f(x) \), where \( f \) names the function and \( x \) represents the input variable.

Input: The independent variable of a function, typically represented by \( x \); the value substituted into the function to produce an output.

Output: The dependent variable of a function, typically represented by \( y \) or \( f(x) \); the result of evaluating the function at a given input.

Range: The set of all possible output values (\(y\)-values) produced by a function; in a real-world context, the range may be restricted to values that are meaningful given the situation.

Solution: An input value (or values) that makes a function equation true for a given output; found by setting \( f(x) \) equal to the desired output and solving.

💡 EXPLORING THE MATH

In today's lesson, we will explore how to use absolute value functions in two variables to solve mathematical and real-world problems. In previous lessons, you learned to graph absolute value functions, identify their key features, and apply transformations. Today you will use those skills purposefully: given a graph or equation of an absolute value function, you will find outputs from inputs, find inputs from outputs, and interpret your answers in the context of a situation. This kind of function work — moving fluently between inputs, outputs, equations, and graphs — is one of the most practical skills in algebra. By the end of this lesson, you will be able to read a graph to answer function questions, use the equation to evaluate or solve, and apply both tools to answer meaningful questions about real-world scenarios modeled by absolute value functions.

Using a Graph to Find an Input or Output

When a function is given as a graph, you can find any output by locating the corresponding input on the horizontal axis and reading the height of the graph at that point. You can also reverse the process — given an output value, locate it on the vertical axis and read the x-value(s) where the graph reaches that height. All results should be expressed using function notation.

Function Notation Reminder

\( f(a) = b \) means: when the input is \( a \), the output is \( b \).

To find an output from the graph: Start at the input value on the x-axis. Move vertically until you reach the graph. Read the y-value. Write your answer as \( f(a) = b \).

To find an input from the graph: Start at the output value on the y-axis. Move horizontally until you reach the graph. Read the x-value(s). Because absolute value graphs are V-shaped, there are often two x-values that produce the same output — one on each arm. Write your answer as \( f(a) = b \) for each solution.


Finding Output from Graph Given the Input

Use the graph of \(f(x)\) to find f(5).

Finding \( f(5) \) — given input, find output:

Locate \( x = 5 \) on the horizontal axis. Move straight up until you hit the graph. Read the y-coordinate: the graph is at height \( 4 \). The red dashed tracers on the graph show this path.

Answer: \( f(5) = 4 \)



Finding Inputs from Graph Given the Output

Use the graph of \(f(x)\) to find f(x)=1.

Finding all \( x \) such that \( f(x) = 1 \) — given output, find input(s):

Locate \( y = 1 \) on the vertical axis. Draw a horizontal line across the graph at that height. The graph is V-shaped, so the horizontal line crosses it at two points: one on the left arm at \( (-5, 1) \) and one on the right arm at \( (3, 1) \). The red dashed tracers show both crossings.

Answer: \( f(-1) = 4 \) and \( f(5) = 4 \)



How many inputs can produce the same output?

Because an absolute value graph is V-shaped, a horizontal line at most heights will cross the graph twice — once on each arm — giving two input values for the same output. At the vertex, the horizontal line just touches the tip of the V and produces exactly one input. A horizontal line drawn below the minimum (or above the maximum for a downward-opening graph) will cross the graph zero times — no solution exists.

The graph below shows \(f(x)\). Use the graph to find \(f(1)\).

Show Solution

Find \( f(1) \):

Locate \( x = 1 \) on the horizontal axis. Move vertically down to the graph. The graph at \( x = 1 \) is at height \( y = -1 \).

Answer:   \( f(1) = -1 \)



Example 2

The graph below shows \(f(x)\). Use the graph to find all values of \(x\) such that \(f(x)=4\).

Show Solution

Find all \( x \) such that \( f(x) = 4 \): Draw a horizontal line at \( y = 4 \). The line crosses the graph at two points: \( x = 2 \) and \( x = 4 \) as shown by the red dashed line.

Answer:   \( f(2) = 4 \)   and   \( f(4) = 4 \). So, \(2,4\).



Using the Equation to Find ab Input or Output

When the equation of a function is given, you can find any output by evaluating the function — substituting the given input directly into the equation and simplifying. To find the input(s) that produce a given output, you set the function equal to the output value and solve the resulting absolute value equation.


Two Directions — Two Processes

Given the input, find the output (evaluate): Substitute the x-value into the equation. Follow the order of operations. Write the answer as \( f(a) = b \).

Example: Find \( f(4) \) for \( f(x) = 2|x - 1| - 3 \).


Given the output, find the input (solve): Replace \( f(x) \) with the given output value. Isolate the absolute value, then split into two cases and solve each. Check for no-solution cases.

Example: Find all \( x \) such that \( f(x) = 5 \) for \( f(x) = 2|x - 1| - 3 \).

Example 3

Let \( f(x) = 3|x + 2| - 5 \). Find \( f(-4) \) and \( f(1) \).

Show Solution

Finding \( f(-4) \): Substitute \( x = -4 \).

\( f(-4) = 3|-4 + 2| - 5 = 3|-2| - 5 = 3(2) - 5 = 6 - 5 = 1 \)

Finding \( f(1) \): Substitute \( x = 1 \).

\( f(1) = 3|1 + 2| - 5 = 3|3| - 5 = 3(3) - 5 = 9 - 5 = 4 \)

Answer: 

Part 1 - \(f(-4)=1\)

Part 2 - \(f(1)=4\)



Example 4

Let \( f(x) = |2x - 4| + 1 \). Find all values of \( x \) such that \( f(x) = 7 \).

Show Solution

Step 1 — Set the function equal to 7:

\( |2x - 4| + 1 = 7 \)

Step 2 — Isolate the absolute value:

\( |2x - 4| = 6 \)

Step 3 — Split into two cases:

Case 1:   \( 2x - 4 = 6 \;\Rightarrow\; 2x = 10 \;\Rightarrow\; x = 5 \)

Case 2:   \( 2x - 4 = -6 \;\Rightarrow\; 2x = -2 \;\Rightarrow\; x = -1 \)

Step 4 — Verify:

\( f(5) = |2(5)-4|+1 = |6|+1 = 7 \) ✓    \( f(-1) = |2(-1)-4|+1 = |-6|+1 = 7 \) ✓

\( f(5) = 7 \) and \( f(-1) = 7 \)

Answer:

The input values \( -1,5 \) both produce an output of \( 7 \).



Example 5

Let \( f(x) = -|x + 3| + 5 \).

  1. Find \( f(0) \).
  2. Find all values of \( x \) such that \( f(x) = 2 \).
  3. Explain why there is no solution to \( f(x) = 8 \).
Show Solution

Part 1 — Evaluate \( f(0) \):

\( f(0) = -|0 + 3| + 5 = -|3| + 5 = -3 + 5 = 2 \)

Part 2 — Solve \( f(x) = 2 \):

\( -|x+3| + 5 = 2 \;\Rightarrow\; -|x+3| = -3 \;\Rightarrow\; |x+3| = 3 \)

Case 1:   \( x + 3 = 3 \;\Rightarrow\; x = 0 \)

Case 2:   \( x + 3 = -3 \;\Rightarrow\; x = -6 \)

Part 3 — Explain no solution for \( f(x) = 8 \):

\( -|x+3| + 5 = 8 \;\Rightarrow\; -|x+3| = 3 \;\Rightarrow\; |x+3| = -3 \)

Absolute value can never equal a negative number, so no value of \( x \) satisfies this equation. The vertex of this function is at \( (-3, 5) \) and the graph opens downward, so the maximum output is \( 5 \). An output of \( 8 \) is above the maximum and is impossible.

Answer:

Part 1:   \( f(0) = 2 \)

Part 2:   \( f(0) = 2 \) and \( f(-6) = 2 \)

Part 3:   No solution — the maximum value of \( f(x) \) is \( 5 \), so \( f(x) = 8 \) has no solution.



Solving Real-World Problems with Absolute Value Functions

Real-world situations are often modeled by absolute value functions because many quantities rise and then fall — or fall and then rise — at a steady rate from a turning point. Once the function is identified, you use the same two skills you just practiced: evaluate the function at a given input to answer "what is the output at this point?", or set the function equal to a given output to answer "when does the quantity reach this level?"

Strategy for Real-World Function Problems

Step 1: Identify what the input variable represents and what the output represents in context.

Step 2: Determine whether you are finding an output (evaluate) or finding an input (solve).

Step 3: Carry out the algebra, then interpret your numerical answer in the context of the problem — including appropriate units.

Step 4: Check whether your answer makes sense given any domain or range constraints stated in the problem.

Example 6

The elevation of a hiking trail above its lowest point is modeled by \( f(x) = -|x - 4| + 9 \), where \( x \) is the horizontal distance in miles from the trailhead and \( f(x) \) is the elevation in hundreds of feet. The trail runs from \( x = 0 \) to \( x = 8 \) miles.

  1. Find \( f(6) \) and interpret the result.
  2. Find the value(s) of \( x \) such that \( f(x) = 6 \) and interpret the result.
  3. What is the maximum elevation, and at what point on the trail does it occur?
Show Solution

Part 1 — Evaluate \( f(6) \):

\( f(6) = -|6 - 4| + 9 = -|2| + 9 = -2 + 9 = 7 \)

Part 2 — Solve \( f(x) = 6 \):

\( -|x - 4| + 9 = 6 \;\Rightarrow\; -|x-4| = -3 \;\Rightarrow\; |x-4| = 3 \)

Case 1:   \( x - 4 = 3 \;\Rightarrow\; x = 7 \)

Case 2:   \( x - 4 = -3 \;\Rightarrow\; x = 1 \)

Both \( x = 1 \) and \( x = 7 \) are within the domain \( [0, 8] \). ✓

Part 3 — Maximum elevation: The function opens downward; vertex is at \( x = 4 \).

\( f(4) = -|4 - 4| + 9 = 0 + 9 = 9 \)

Answer:

Part 1:   \( f(6) = 7 \) — At 6 miles from the trailhead, the trail is 700 feet above the lowest point.

Part 2:   \( f(1) = 6 \) and \( f(7) = 6 \) — The trail is 600 feet above the lowest point at two locations: 1 mile and 7 miles from the trailhead.

Part 3:   \( f(4) = 9 \) — The maximum elevation is 900 feet above the lowest point, occurring at 4 miles from the trailhead.



Example 7

A community theater tracks weekly ticket revenue. Based on historical data, the weekly revenue in hundreds of dollars is modeled by \( f(x) = -3|x - 5| + 12 \), where \( x \) is the number of weeks since a new show opened and \( f(x) \) is the revenue in hundreds of dollars. The show runs for 9 weeks.

  1. Find \( f(2) \) and interpret the result.
  2. Find all values of \( x \) such that \( f(x) = 6 \) and interpret the result.
  3. During which weeks does the theater break even, defined as \( f(x) = 0 \)?
Show Solution

Part 1 — Evaluate \( f(2) \):

\( f(2) = -3|2 - 5| + 12 = -3|-3| + 12 = -3(3) + 12 = -9 + 12 = 3 \)

Part 2 — Solve \( f(x) = 6 \):

\( -3|x-5| + 12 = 6 \;\Rightarrow\; -3|x-5| = -6 \;\Rightarrow\; |x-5| = 2 \)

Case 1:   \( x - 5 = 2 \;\Rightarrow\; x = 7 \)

Case 2:   \( x - 5 = -2 \;\Rightarrow\; x = 3 \)

Part 3 — Solve \( f(x) = 0 \):

\( -3|x-5| + 12 = 0 \;\Rightarrow\; |x-5| = 4 \)

Case 1:   \( x = 9 \)    Case 2:   \( x = 1 \)

Both \( x = 1 \) and \( x = 9 \) fall within the 9-week run. ✓

Part 1:   \( f(2) = 3 \) — In week 2, the theater earns $300 in ticket revenue.

Part 2:   \( f(3) = 6 \) and \( f(7) = 6 \) — The theater earns $600 in week 3 and again in week 7.

Part 3:   \( f(1) = 0 \) and \( f(9) = 0 \) — The theater breaks even (earns $0 in modeled revenue) in week 1 and week 9, the opening and closing weeks of the run.



Conclusion

In this lesson, you developed two complementary tools for solving problems involving absolute value functions in two variables: reading a graph and working with an equation. From a graph, you learned to trace from a given input to its output, and to reverse the process — starting from a known output and identifying the input value or values where the graph reaches that height. You practiced expressing all results in function notation, which gives you a precise and efficient language for communicating function relationships. From an equation, you evaluated the function by substituting a known input, and you solved for unknown inputs by setting the function equal to a given output and applying the two-case method for absolute value equations. You also explored the special cases of no solution and maximum or minimum outputs. Finally, you applied both strategies to real-world scenarios — hiking trails, ticket sales, lake temperatures, and drone flight paths — interpreting every numerical answer in context and checking solutions against domain constraints. These skills connect every part of your work with absolute value functions this unit: graphing, key features, transformations, and now purposeful problem-solving. They also lay the groundwork for broader function work throughout the rest of the course.
