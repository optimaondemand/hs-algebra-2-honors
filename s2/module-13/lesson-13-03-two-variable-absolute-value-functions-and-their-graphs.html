📚 VOCABULARY

Absolute Value Function: A function of the form \( f(x) = |x| \) or a transformation of it, producing a V-shaped graph composed of two linear rays meeting at a vertex.

Axis of Symmetry: A vertical line that passes through the vertex of an absolute value function and divides the graph into two mirror-image halves; written as \( x = h \) where \( h \) is the x-coordinate of the vertex.

Constraint: A restriction placed on the domain or range of a function based on the limits of a real-world context, such as time or distance not being able to take negative values.

Domain: The set of all possible input values (x-values) for a function.

Interval of Decrease: A portion of the domain over which the output values of a function are getting smaller as the input increases; written in interval notation.

Interval of Increase: A portion of the domain over which the output values of a function are getting larger as the input increases; written in interval notation.

Piecewise Linear: A description of a function whose graph is composed of two or more straight-line segments; the absolute value function is piecewise linear because each half of the V is a straight ray with a constant rate of change.

Range: The set of all possible output values (y-values) produced by a function.

Rate of Change: The ratio of the change in output to the change in input over an interval; for an absolute value function, the rate of change is constant on each linear piece but opposite in sign on either side of the vertex.

Vertex: The point at which the two linear pieces of an absolute value graph meet; the minimum point of the graph when the function opens upward, or the maximum point when it opens downward.

x-intercept: The point(s) where the graph of a function crosses the x-axis; the value(s) of \(x\) when \( f(x) = 0 \).

y-intercept: The point where the graph of a function crosses the y-axis; the value of \( f(x) \) when \( x = 0 \).

💡 EXPLORING THE MATH

In today's lesson, we will explore the graphs of absolute value functions — what they look like, what their key features tell us, and how to build the graph of any absolute value function directly from its equation. You have already worked with absolute value expressions and equations, so you know that absolute value measures distance from zero and always produces a non-negative result. That same idea shapes the graph in a very specific and recognizable way. In this lesson, you will begin by studying the simplest absolute value function, called the parent function, and identify its key features from the graph. Then you will learn how to identify those features directly from an equation of the form \( f(x) = a|x - h| + k \) and use them to graph the function without a table of values. Finally, you will apply these skills to real-world situations where absolute value functions model practical scenarios, and you will interpret key features and decide what constraints are appropriate given the context.

The Parent Function \( f(x) = |x| \)

The parent function of the absolute value family is \( f(x) = |x| \). It is the simplest version of the function — no shifting, no stretching, no reflecting. Every other absolute value function is built from this foundation. Understanding its graph and key features gives you a reference point for everything that follows.

The graph of \( f(x) = |x| \) is V-shaped, opening upward, with the point of the V sitting exactly at the origin. Each side of the V is a straight ray with a constant rate of change — the left side falls at a rate of \( -1 \) and the right side rises at a rate of \( +1 \). This makes the graph piecewise linear: two straight-line pieces joined at a single point.

Key Features of \( f(x) = |x| \)

  • Vertex:   \( (0, 0) \) — the lowest point of the graph, where the two rays meet.
  • Axis of Symmetry:   \( x = 0 \) — the y-axis; the graph is a mirror image on either side.
  • x-intercept:   \( (0, 0) \) — the graph crosses the x-axis at the origin.
  • y-intercept:   \( (0, 0) \) — the graph crosses the y-axis at the origin.
  • Domain:   All real numbers, \( (-\infty, \infty) \)
  • Range:   \( y \geq 0 \), written \( [0, \infty) \)
  • Interval of Decrease:   \( (-\infty, 0) \) — as x increases toward 0 from the left, the function values decrease.
  • Interval of Increase:   \( (0, \infty) \) — as x increases from 0 to the right, the function values increase.

Notice that the vertex is the point where the function switches from decreasing to increasing. It will always be the boundary between the two intervals, and it is the starting point for identifying all other key features on any absolute value graph.



Reading Key Features from Any Absolute Value Graph

Once a function has been shifted, stretched, or reflected from the parent, the graph still holds the same V-shape and the same set of key features — but the values change. You can read all key features directly from the graph without the equation.

How to Read Key Features from a Graph

Vertex: Locate the point where the two rays meet — the tip of the V. Read its coordinates \( (h, k) \).

Axis of Symmetry: Write the vertical line through the vertex: \( x = h \).

x-intercept(s): Locate where the graph crosses the x-axis. Read the x-value(s). Some graphs may have zero, one, or two x-intercepts. When \(y=0\)

y-intercept: Locate where the graph crosses the y-axis. Read the y-value. When \(x=0\)

Domain: Absolute value functions are defined for all real numbers unless a real-world context restricts them: \( (-\infty, \infty) \) or \(-\infty < x < \infty\)

Range: Identify the vertex's y-value \( k \). If the graph opens upward, the range is \( [k, \infty) \) or \(y \geq k\). If it opens downward, the range is \( (-\infty, k] \) or \(y \leq k\).

Intervals of Increase/Decrease: Moving left to right — identify where the graph is falling (decreasing) and where it is rising (increasing). The vertex x-value is always the boundary.

Identify all key features of the graph shown.

The equation of this function is \( f(x) = |x - 3| + 1 \).

Vertex:   \( (3, 1) \)

Axis of Symmetry:   \( x = 3 \)

y-intercept:   \( (0, 4) \) — substitute \( x = 0 \):   \( f(0) = |0 - 3| + 1 = 3 + 1 = 4 \)

Interval of Increase:   \( (3, \infty) \)

Range:  — the graph opens upward with a minimum y-value of \( -3 \).

Interval Notation: \( [-3, \infty) \) 

Inequality: \(x \geq -3\)

Interval of Decrease:   \( (-\infty, 0) \)

Interval of Increase:   \( (0, \infty) \)

 

Graphing an Absolute Value Function from Its Equation

When an absolute value function is written in the form \( f(x) = a|x - h| + k \), the equation contains all the information you need to build the graph without plotting a large table of values. You only need to identify three things: the vertex, the direction the graph opens, and the rate of change on each arm.

Reading \( f(x) = a|x - h| + k \)

Vertex:   The vertex is at \( (h,\ k) \). Watch the sign carefully — because the form uses \( (x - h) \), the x-coordinate of the vertex is the value of \( h \) that makes the expression inside the bars equal to zero. For example, in \( |x - 3| \), the vertex is at \( x = 3 \); in \( |x + 2| \), rewrite as \( |x - (-2)| \), so the vertex is at \( x = -2 \).

Direction:   If \( a > 0 \), the graph opens upward. If \( a < 0 \), the graph opens downward.

Rate of Change:   The value of \( |a| \) gives the rate of change on each arm. Starting from the vertex, move 1 unit right and \( |a| \) units up (or down if \( a < 0 \)), then repeat on the left side symmetrically.



Steps to Graph \( f(x) = a|x - h| + k \):

  1. Identify \( h \) and \( k \). Plot the vertex at \( (h, k) \).
  2. Draw the axis of symmetry as a dashed vertical line through \( x = h \).
  3. Use the rate of change \( |a| \): from the vertex, move 1 unit right and \( |a| \) units up or down. Plot that point. Reflect it across the axis of symmetry to get the matching point on the left arm.
  4. Connect the three points with straight rays extending outward.
  5. Identify the y-intercept by substituting \( x = 0 \) and verify it lies on the graph.



Graph \( f(x) = 2|x - 1| - 4 \)

Step 1 — Vertex: \( h = 1 \), \( k = -4 \). Vertex: \( (1, -4) \).

Step 2 — Direction: \( a = 2 > 0 \), so the graph opens upward.

Step 3 — Rate of change: \( |a| = 2 \). From the vertex, move 1 right and 2 up → point \( (2, -2) \). Reflect to get \( (0, -2) \).

Step 4 — Connect: Draw rays through \( (0,-2) \to (1,-4) \to (2,-2) \) and beyond.

Step 5 — y-intercept check: \( f(0) = 2|0-1|-4 = 2(1)-4 = -2 \). Point \( (0,-2) \) ✓ already plotted.

x-intercepts: \( 2|x-1| - 4 = 0 \Rightarrow |x-1| = 2 \Rightarrow x = 3 \) or \( x = -1 \)

Example 4

Graph the function and identify all key features.

\( f(x) = |x - 2| + 3 \)

Show Solution

Vertex: \( h = 2,\ k = 3 \) → Vertex: \( (2, 3) \)

Direction: \( a = 1 > 0 \) → opens upward.

Rate of change: \( |a| = 1 \). From vertex: 1 right, 1 up → \( (3, 4) \). Reflect → \( (1, 4) \).

y-intercept: \( f(0) = |0-2|+3 = 5 \) → \( (0, 5) \)

x-intercepts: \( |x-2|+3 = 0 \Rightarrow |x-2| = -3 \) → No solution; no x-intercepts.

Answer:

Vertex:   \( (2, 3) \)

Axis of Symmetry:   \( x = 2 \)

x-intercept(s):   None

y-intercept:   \( (0, 5) \)

Domain:   \( (-\infty, \infty) \) or \( -\infty < x < \infty\)

Range:   \( [3, \infty) \) or \( y \geq 3\)

Interval of Decrease:   \( (-\infty, 2) \)

Interval of Increase:   \( (2, \infty) \)

Graph the function and identify all key features.

\( f(x) = -3|x + 2| + 6 \)

Show Solution

Vertex: \( h = -2,\ k = 6 \) → Vertex: \( (-2, 6) \)

Direction: \( a = -3 < 0 \) → opens downward.

Rate of change: \( |a| = 3 \). From vertex: 1 right, 3 down (because \( a \) is negative) → \( (-1, 3) \). Reflect → \( (-3, 3) \).

y-intercept: \( f(0) = -3|0+2|+6 = -6+6 = 0 \) → \( (0, 0) \)

x-intercepts: \( -3|x+2|+6 = 0 \Rightarrow |x+2| = 2 \Rightarrow x = 0 \) or \( x = -4 \)

Vertex:   \( (-2, 6) \)

Axis of Symmetry:   \( x = -2 \)

x-intercept(s):   \( (-4, 0) \) and \( (0, 0) \)

y-intercept:   \( (0, 0) \)

Domain:   \( (-\infty, \infty) \) or \(-\infty < x < \infty \)

Range:   \( (-\infty, 6] \) or \(y \leq 6\)

Interval of Increase:   \( (-\infty, -2) \)

Interval of Decrease:   \( (-2, \infty) \)

 

Absolute Value Functions in Real-World Contexts

Absolute value functions appear in real-world situations whenever a quantity rises and then falls — or falls and then rises — at a steady rate from a specific turning point. The vertex of the function represents that turning point, and its coordinates carry direct meaning in context. Key features such as intercepts, domain, and range take on practical interpretations, and real-world constraints often limit the domain and range to values that make sense in the situation.

What Each Feature Means in Context

Vertex: The turning point of the situation — a minimum cost, a peak height, the closest distance, the lowest temperature, etc.

x-intercept(s): The input value(s) at which the output equals zero — when a quantity reaches its baseline, breaks even, or returns to its starting level.

y-intercept: The output value when the input is zero — the starting value at the beginning of the situation.

Domain constraint: The set of input values that are meaningful in context. Time cannot be negative; a number of items cannot be a fraction; a distance cannot exceed a physical limit.

Range constraint: The set of output values that are meaningful in context. A price cannot be negative; a temperature may have a physical lower bound; a count cannot exceed a known maximum.

Example 6  —  Drone Delivery

A delivery drone travels in a straight path. Its altitude in feet above the ground is modeled by the function \( f(x) = -2|x - 5| + 10 \), where \( x \) represents the horizontal distance traveled in hundreds of feet from the launch point, and \( f(x) \) represents the altitude of the drone in feet. The drone's flight path ends when it lands.

Identify and interpret all key features. Then determine any constraints on the domain and range based on the context.

Show Solution

Vertex: \( h = 5,\ k = 10 \) → \( (5, 10) \). The drone reaches its maximum altitude of 10 feet when it has traveled 500 feet horizontally.

Direction: \( a = -2 < 0 \) → graph opens downward. The drone rises to the vertex, then descends — consistent with a flight path.

x-intercepts: Set \( f(x) = 0 \):   \( -2|x-5|+10=0 \Rightarrow |x-5|=5 \Rightarrow x=0 \) or \( x=10 \). The drone launches at \( x = 0 \) (0 feet from start) and lands at \( x = 10 \) (1,000 feet from start).

y-intercept: \( f(0) = -2|0-5|+10 = -10+10 = 0 \). The altitude is 0 feet at launch — the drone starts on the ground.

Axis of Symmetry: \( x = 5 \). The flight path is symmetric; the drone takes the same path up as it does down.

Rate of change: \( |a| = 2 \). The altitude changes by 2 feet for every 100 feet of horizontal distance traveled.

Answer:

Domain (mathematical):   All real numbers, \( (-\infty, \infty) \)

Domain (contextual constraint):   \( [0, 10] \) or \(0 \leq x \leq 10\) — the drone only travels from its launch point \( (x=0) \) to its landing point \( (x=10) \); distances before launch or after landing have no meaning here.

Range (mathematical):   \( (-\infty, 10] \)

Range (contextual constraint):   \( [0, 10] \) or \(0 \leq y \leq 10\) — the drone cannot fly at a negative altitude; altitude is bounded below by 0 (the ground) and above by 10 feet at the vertex.

Summary: The drone launches from the ground, climbs to a peak altitude of 10 feet at 500 feet of horizontal distance, then descends and lands at 1,000 feet from the launch point. Its full flight covers a horizontal distance of 1,000 feet.



Example 7  —  Parking Garage Pricing

A parking garage offers a promotional discount on its hourly rate. The cost per hour in dollars is modeled by the function \( f(x) = |x - 4| + 2 \), where \( x \) represents the number of hours parked and \( f(x) \) represents the cost per hour in dollars. The garage allows parking for a maximum of 8 hours.

Identify and interpret all key features. Then determine any constraints on the domain and range based on the context.

Show Solution

Vertex: \( h = 4,\ k = 2 \) → \( (4, 2) \). The minimum cost per hour is $2.00, reached at exactly 4 hours of parking.

Direction: \( a = 1 > 0 \) → graph opens upward. The rate starts high, decreases to the minimum at 4 hours, then increases — the garage offers its best rate at the 4-hour mark.

x-intercepts: Set \( f(x) = 0 \):   \( |x-4|+2=0 \Rightarrow |x-4|=-2 \) → No solution. The cost per hour is never zero; there are no x-intercepts.

y-intercept: \( f(0) = |0-4|+2 = 4+2 = 6 \). At 0 hours, the cost per hour would be $6.00. In context, this represents the initial hourly rate before the discount takes effect.

Axis of Symmetry: \( x = 4 \). The rate decreases and increases symmetrically around the 4-hour mark.

Rate of change: \( |a| = 1 \). The cost per hour changes by $1.00 for every additional hour parked away from the 4-hour midpoint.

Answer:

Domain (mathematical):   All real numbers, \( (-\infty, \infty) \)

Domain (contextual constraint):   \( [0, 8] \) or \(0 \leq x \leq 8\) — parking time cannot be negative, and the garage has a maximum of 8 hours. Only \( x \)-values from 0 to 8 are meaningful.

Range (mathematical):   \( [2, \infty) \)

Range (contextual constraint):   \( [2, 6] \) or \(2 \leq y \leq 6\) — the minimum cost per hour is $2.00 (at 4 hours) and the maximum cost per hour within the allowed 8-hour window is \( f(8) = |8-4|+2 = 6 \) or \( f(0) = 6 \), which is $6.00. Costs outside this range do not occur within the parking window.

Summary: The parking garage charges $6.00 per hour at the start, lowers the rate to a minimum of $2.00 per hour at the 4-hour mark, then raises it back to $6.00 per hour at 8 hours. The discount is greatest at exactly 4 hours of parking.

 


Conclusion

In this lesson, you explored absolute value functions from the ground up — beginning with the parent function \( f(x) = |x| \) and building toward reading, graphing, and interpreting more complex forms. You learned that the V-shaped graph is piecewise linear, meaning each arm has a constant rate of change, and that the vertex is the central feature from which all other key features are organized. From any graph, you can identify the vertex, axis of symmetry, intercepts, domain, range, and intervals of increase and decrease. From any equation in the form \( f(x) = a|x - h| + k \), you can extract those same features directly and construct an accurate graph without a full table of values. Finally, you applied these skills to real-world contexts, discovering that mathematical features carry meaningful interpretations in context and that practical constraints often restrict the domain and range to values that make physical or logical sense. In the next lesson, you will build on this foundation by studying how changes to the values of \( a \), \( h \), and \( k \) transform the graph — connecting the equation to precise visual changes in a systematic way.
