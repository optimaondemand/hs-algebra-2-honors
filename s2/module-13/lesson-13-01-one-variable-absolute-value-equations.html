📚 VOCABULARY

Absolute Value: The distance of a number from zero on a number line, always expressed as a non-negative value; written as \(|x|\).

Case: One of the two possible equations formed when solving an absolute value equation, representing either the positive or negative interpretation of the expression inside the absolute value symbols.

Equation: A mathematical statement asserting that two expressions are equal, indicated by an equals sign.

Extraneous Solution: A value obtained algebraically that does not satisfy the original equation when substituted back in.

Isolation: The process of rewriting an equation so that the absolute value expression is alone on one side before splitting into two cases.

No Solution: The result when an absolute value equation is set equal to a negative number, since absolute value cannot be negative.

Solution Set: The collection of all values that make an equation true.

Variable: A symbol, typically a letter, used to represent an unknown quantity in an equation.

💡 EXPLORING THE MATH

In today's lesson, we will explore absolute value equations — what they mean, why they behave differently from other equations you have solved, and how to find their solutions. You will learn that absolute value is rooted in a simple idea: distance. From there, you will build a reliable process for solving any one-variable absolute value equation, whether the numbers are tucked inside the absolute value bars, sitting outside them, or both. By the end of this lesson, you will be able to write and solve absolute value equations with confidence, recognize when a solution needs to be rejected, and know when an equation has no solution at all.

What Is Absolute Value?

The absolute value of a number is its distance from zero on a number line. Distance is always a non-negative quantity — you cannot travel a negative number of steps — so absolute value is always zero or positive.

The absolute value of a number \( x \) is written as \( |x| \).

Key Examples \( |3| = 3 \)    \( |-3| = 3 \)    \( |0| = 0 \)    \( |-7| = 7 \)

Notice that both \( 3 \) and \( -3 \) are exactly 3 units from zero. This is the key idea that makes absolute value equations unique — and it is the reason they produce two solutions in most cases.



What Does a Solution of an Absolute Value Equation Represent?

When you solve an absolute value equation, you are answering the question: "What values of x make the distance expression equal to a given amount?"

Because two different numbers can be the same distance from zero (one positive, one negative), absolute value equations typically have two solutions.

Thinking About It If \( |x| = 5 \), you are asking: "What numbers are exactly 5 units from zero?" The answer is \( x = 5 \) and \( x = -5 \). Both work. Both are solutions.

There are two special cases worth knowing before you begin solving:

  • One solution: If the absolute value expression equals zero, there is only one solution — for example, \( |x| = 0 \) gives \( x = 0 \).
  • No solution: If the absolute value expression is set equal to a negative number, there is no solution. Distance can never be negative, so no value of \( x \) can satisfy the equation.



How to Solve an Absolute Value Equation

Coefficients and constants can appear inside the absolute value bars, outside the bars, or both. Regardless of where they appear, always follow these steps in order:

The Process — Always Follow This Order
  1. Isolate the absolute value expression on one side by undoing any addition, subtraction, multiplication, or division that is outside the bars first.
  2. Check the right side. If it is negative → No Solution. If it is zero or positive → continue.
  3. Split into two cases: set the expression inside the bars equal to the positive value, and then set it equal to the negative value.
  4. Solve each case as a separate linear equation.
  5. Check both solutions by substituting back into the original equation.



Coefficient and Constant Inside the Absolute Value

Solve: \( |2x + 3| = 11 \)

The coefficient \( 2 \) and constant \( +3 \) are both inside the absolute value bars. There is nothing outside the bars to undo, so the absolute value is already isolated. Proceed directly to splitting into two cases.

Step 1 \(|2x+3|=11\) Already isolated. Right side is positive - continue.
Case 1 \(2x+3=11\) Set the inside equal to \(+11\).
Subtract 3 from both sides.
Divide both sides by 2
Case 2 \(2x+3=-11\) Set the inside equal to \(-11\).
Subtract 3 from both sides.
Divide both sides by 2.
Check

Both solutions verify in the original equation. Write as a solution set inside { }.

Solution: \( \{-7, 4\} \)


Coefficient and Constant Outside the Absolute Value

Solve: \( 3|x - 4| + 2 = 14 \)

The coefficient \( 3 \) and constant \( +2 \) are both outside the absolute value bars. Undo those operations first to isolate the absolute value before splitting into two cases.

Step 1a \(3|x-4|+2=14\)
Undo the \(+2\) outside the bars by subtracting 2 from both sides.
Step1b Divide both sides 3. The absolute value is not isolated. Right side is positive - continue.
Case 1 Set the inside equal to \(+4\).
Add 4 to both sides.
Case 2 \(x-4=-4\) Set the inside equal to \(-4\).
Add 4 to both sides.
Check

Both solutions verify in the original equation. Write as a solution set using { }.

Solution: \( \{0, 8\} \)

📌 Quick Reference — Key Rules

• Isolate the absolute value expression before splitting into two cases.
• Always split into a positive case and a negative case.
• If the isolated absolute value equals a negative number → No Solution.
• Always verify both solutions in the original equation.



Conclusion

In this lesson, you learned that absolute value represents distance from zero — a concept that gives absolute value equations their unique character. Because distance can be measured in two directions, most absolute value equations produce two solutions, one from the positive case and one from the negative case. You practiced a dependable process: isolate the absolute value first, check whether the right side is negative before going further, split into two cases, solve each one, and verify your answers. You also saw that when isolating the absolute value results in a negative value on the right side, the equation has no solution. These skills apply in both purely mathematical settings and real-world situations where a quantity is allowed to vary a certain distance from a target value. As you move forward, keep this process in mind — it will serve as the foundation for more advanced work with absolute value inequalities and functions later in the course.
