📚 VOCABULARY

Arithmetic Operations: The four basic mathematical operations (addition, subtraction, multiplication, and division) that can be applied to functions as well as numbers.

Closed-form Expression: A mathematical expression that can be evaluated in a finite number of standard operations; the simplified result of combining functions.

Degree: The highest exponent of the variable in a polynomial function, used to classify and predict the behavior of the resulting combined function.

Difference of Functions: The new function formed by subtracting one function from another: \( (f - g)(x) = f(x) - g(x) \).

Domain: The complete set of possible input values \( x \)-values for which a function is defined.

Domain Restriction: A limitation placed on the input values of a function to exclude values that produce undefined or contextually unreasonable outputs.

Exponential Function: A function of the form \( f(x) = ab^x \), where the variable appears as an exponent.

Function Notation: A symbolic way of representing a function, such as \( f(x) \), used to clarify input-output relationships and operations between functions.

Linear Function: A function of the form \( f(x) = mx + b \) whose graph is a straight line.

Polynomial Function: A function consisting of variables raised to non-negative integer exponents with real-number coefficients; includes linear and quadratic functions as special cases.

Product of Functions: The new function formed by multiplying two functions together: \( (f \cdot g)(x) = f(x) \cdot g(x) \).

Quadratic Function: A polynomial function of degree 2, written in the form \( f(x) = ax^2 + bx + c \).

Quotient of Functions: The new function formed by dividing one function by another: \( \left(\dfrac{f}{g}\right)(x) = \dfrac{f(x)}{g(x)} \), where \( g(x) \neq 0 \).

Range: The complete set of possible output values \( y \)-values produced by a function.

Sum of Functions: The new function formed by adding two functions together: \( (f + g)(x) = f(x) + g(x) \).

Undefined: A value or expression that has no mathematical meaning, most commonly occurring when dividing by zero.

💡 EXPLORING THE MATH

In this lesson, you will learn how to combine two functions using addition, subtraction, multiplication, and division to create a new function rule. You will also learn how to identify any restrictions on the domain of the new function, and how to evaluate combined functions at a specific input value.

Applying Arithmetic Operations to Create a New Function Rule

What Does It Mean to Combine Functions?

You already know how to add, subtract, multiply, and divide numbers and algebraic expressions. The same arithmetic operations can be applied directly to functions. When you apply an operation to two functions, the result is a brand-new function with its own rule.

Given two functions \(f(x)\) and \(g(x)\), the four arithmetic combinations are defined as:

Sum: \((f + g)(x) = f(x) + g(x)\)

Difference: \((f - g)(x) = f(x) - g(x)\)

Product: \((f \cdot g)(x) = f(x) \cdot g(x)\)

Quotient: \(\left(\dfrac{f}{g}\right)(x) = \dfrac{f(x)}{g(x)}\), provided \(g(x) \neq 0\)

In this lesson, we will work with linear, quadratic, exponential, and polynomial functions.


Domain Restrictions

The domain of a combined function is the set of all input values for which the new function is defined. Linear, quadratic, polynomial, and exponential functions are each defined for all real numbers on their own, so when you add, subtract, or multiply them, the resulting function is typically also defined for all real numbers — no restrictions needed.

The important exception is division. When you divide two functions, you must exclude any input value where the denominator equals zero, because division by zero is undefined. This creates a domain restriction.

Key Rule: For \(\left(\dfrac{f}{g}\right)(x)\), always set \(g(x) = 0\) and solve. Any solution is a restricted value that must be excluded from the domain.

Important: Always identify the domain restriction before simplifying the quotient. Even if the expression simplifies in a way that appears defined at the restricted value, the restriction must still be stated.


Sum of Two Functions

Let \(f(x) = 2x + 5\) and \(g(x) = x^2 - 3\). Find \((f + g)(x)\) and state any domain restrictions.

Step 1: Apply the definition of the sum of functions.

Step 2: Combine like terms.

Step 3: Check for domain restrictions. Both \(f(x)\) (linear) and \(g(x)\) (quadratic) are polynomials defined for all real numbers. Since we are adding — not dividing — there are no domain restrictions.

Answer: \((f + g)(x) = x^2 + 2x + 2\).

Domain: all real numbers.

Interval Notation: \((-\infty, \infty)\)

Inequality Notation: \(-\infty < x < \infty \)



Quotient of Two Functions

Let \(f(x) = x^2 - 9\) and \(g(x) = x - 3\). Find \(\left(\dfrac{f}{g}\right)(x)\) and state any domain restrictions.

Step 1: Apply the definition of the quotient of functions.

Step 2: Identify the domain restriction first. Set the denominator equal to zero.

\(x - 3 = 0 \Rightarrow x = 3\), so \(x \neq 3\)

Step 3: Simplify by factoring the numerator as a difference of squares.

Answer: .

Domain: all real numbers except \(x = 3\).

Interval Notation:

Inequality Notation: \(x<3\; \text{or}\; x>3\)

Example 1

Let \(f(x) = 4x + 1\) and \(g(x) = x^2 - 2x + 3\). Find \((f \cdot g)(x)\) and state any domain restrictions.

Show Solution and Explanation

Step 1: Apply the definition of the sum of functions.

\((f \cdot g)(x) = f(x) \cdot g(x) = (4x + 1) \cdot (x^2 - 2x + 3)\)

Step 2: Distribute the terms in the first parentheses to all terms in the second one.

Step 3: Combine like terms.

\((f + g)(x) = 4x^3+(-8x^2+x^2)+(12x-2x)+3=4x^3-7x^2+10x+3\)

Step 4: Check for domain restrictions. \(f(x) = 4x + 1\) is a linear function and \(g(x) = x^2 - 2x + 3\) is a quadratic function. Both are polynomials defined for all real numbers. Because we are multiplying the two functions, no values of \(x\) make the new function undefined.

Answer: \((f \cdot g)(x) = 4x^3-7x^2+10x+3\). Domain: all real numbers.



Example 2

Let \(f(x) = 2x^3 + x\) and \(g(x) = x^2 + 3x - 1\). Find \((f - g)(x)\) and state any domain restrictions.

Show Solution and Explanation

Step 1: Apply the definition of the difference of functions.

\((f - g)(x) = f(x) - g(x) = (2x^3 + x) - (x^2 + 3x - 1)\)

Step 2: Distribute the negative sign across every term in \(g(x)\). This is the most common place students make errors — be sure to change the sign of every term inside the parentheses.

\((f - g)(x) = 2x^3 + x - x^2 - 3x + 1\)

Step 3: Combine like terms and write in standard form (highest degree first).

\((f - g)(x) = 2x^3 - x^2 + (x - 3x) + 1 = 2x^3 - x^2 - 2x + 1\)

Step 4: Check for domain restrictions. Both \(f(x)\) (a cubic polynomial) and \(g(x)\) (a quadratic polynomial) are defined for all real numbers. Subtraction does not create any domain restrictions.

Answer: \((f - g)(x) = 2x^3 - x^2 - 2x + 1\). Domain: all real numbers.



Example 3

Let \(f(x) = x^2 - 4\) and \(g(x) = x - 2\). Find \(\left(\dfrac{f}{g}\right)(x)\) and state any domain restrictions.

Show Solution and Explanation

Step 1: Apply the definition of the quotient of functions.

\(\left(\dfrac{f}{g}\right)(x) = \dfrac{f(x)}{g(x)} = \dfrac{x^2 - 4}{x - 2}\)

Step 2: Identify the domain restriction before simplifying. Set the denominator equal to zero and solve.

\(x - 2 = 0 \Rightarrow x = 2\), so \(x \neq 2\)

Since division by zero is undefined, \(x = 2\) must be excluded from the domain.

Step 3: Simplify the quotient by factoring the numerator. Notice that \(x^2 - 4\) is a difference of squares: \(x^2 - 4 = (x + 2)(x - 2)\).

\(\dfrac{(x + 2)(x - 2)}{x - 2} = x + 2\), where \(x \neq 2\)

Important note: Even though the simplified expression \(x + 2\) would be defined at \(x = 2\), the restriction \(x \neq 2\) must still be stated because the original denominator was undefined there. The domain of the combined function was determined before simplification.

Answer: \(\left(\dfrac{f}{g}\right)(x) = x + 2\), where \(x \neq 2\). Domain: all real numbers except \(x = 2\).

 



Evaluating Combined Functions at a Given Input Value

How to Evaluate a Combined Function

Once you have identified the combined function and any domain restrictions, you may be asked to evaluate it at a specific input value. There are two approaches, and both will give you the same result:

Method 1 — Evaluate the new function rule directly: Substitute the input value into the simplified combined function rule you found in Part 1.

Method 2 — Evaluate each function separately first: Find \(f(a)\) and \(g(a)\) individually, then apply the operation.

For example, to find \((f + g)(a)\):

\((f + g)(a) = f(a) + g(a)\)

Before evaluating, always check that the input value is in the domain of the combined function. If the input value is a restricted value, the expression is undefined.



Evaluate Difference of Two Functions

Let \(f(x) = x^2 + 2\) and \(g(x) = 3x - 1\). Find \((f - g)(4)\).

Step 1: Identify the operation and check the domain. Both functions are polynomials, so there are no restrictions. The value \(x = 4\) is in the domain.

Step 2: Evaluate \(f(4)\) and \(g(4)\) separately.

\(f(4) = (4)^2 + 2 = 16 + 2 = 18\)

\(g(4) = 3(4) - 1 = 12 - 1 = 11\)

Step 3: Apply the operation.

\((f - g)(4) = f(4) - g(4) = 18 - 11 = 7\)

Answer: \((f - g)(4) = 7\)



Evaluate Quotient of Two Functions

Let \(f(x) = 2^x\) and \(g(x) = x^2 - 1\). Find \(\left(\dfrac{f}{g}\right)(3)\).

Step 1: Check the domain restriction. Since we are dividing, the values that make \(g(x)\) equal 0 will be restrictions on the domain.

Set \(g(x) = 0\): \(x^2 - 1 = 0 \Rightarrow x = \pm 1\). So \(x \neq 1\) and \(x \neq -1\). Since \(x = 3\) is not a restricted value, we may proceed.

Step 2: Evaluate \(f(3)\) and \(g(3)\) separately.

\(f(3) = 2^3 = 8\)

\(g(3) = (3)^2 - 1 = 9 - 1 = 8\)

Step 3: Apply the operation.

\(\left(\dfrac{f}{g}\right)(3) = \dfrac{f(3)}{g(3)} = \dfrac{8}{8} = 1\)

Answer: \(\left(\dfrac{f}{g}\right)(3) = 1\)

Example 4

Let \(f(x) = 2x + 1\) and \(g(x) = x^2 - 3\). Find \((f + g)(3)\).

Show Solution and Explanation

Step 1: Identify the operation and check the domain. Both functions are polynomials with no restrictions. The value \(x = 3\) is in the domain.

Step 2: Evaluate \(f(3)\) and \(g(3)\) separately.

\(f(3) = 2(3) + 1 = 6 + 1 = 7\)

\(g(3) = (3)^2 - 3 = 9 - 3 = 6\)

Step 3: Apply the addition operation.

\((f + g)(3) = f(3) + g(3) = 7 + 6 = 13\)

Answer: \((f + g)(3) = 13\)



Example 5

Let \(f(x) = 2^x\) and \(g(x) = x + 1\). Find \((f \cdot g)(3)\).

Show Solution and Explanation

Step 1: Identify the operation and check the domain. \(f(x) = 2^x\) is an exponential function defined for all real numbers, and \(g(x) = x + 1\) is a linear function also defined for all real numbers. Since we are multiplying, there are no domain restrictions. The value \(x = 3\) is in the domain.

Step 2: Evaluate \(f(3)\) and \(g(3)\) separately.

\(f(3) = 2^3 = 8\)

\(g(3) = 3 + 1 = 4\)

Step 3: Apply the multiplication operation.

\((f \cdot g)(3) = f(3) \cdot g(3) = 8 \cdot 4 = 32\)

Answer: \((f \cdot g)(3) = 32\)



Example 6

Let \(f(x) = x^2 - 16\) and \(g(x) = x - 4\). Find \(\left(\dfrac{f}{g}\right)(6)\).

Show Solution and Explanation

Step 1: Check the domain restriction first. Set the denominator equal to zero and solve.

\(x - 4 = 0 \Rightarrow x = 4\), so \(x \neq 4\)

Since we are evaluating at \(x = 6\), and \(6 \neq 4\), we are not at a restricted value and may proceed.

Step 2: Evaluate \(f(6)\) and \(g(6)\) separately.

\(f(6) = (6)^2 - 16 = 36 - 16 = 20\)

\(g(6) = 6 - 4 = 2\)

Step 3: Apply the division operation.

\(\left(\dfrac{f}{g}\right)(6) = \dfrac{f(6)}{g(6)} = \dfrac{20}{2} = 10\)

Bonus check: You could also simplify the combined function first. Factoring the numerator: \(\dfrac{(x+4)(x-4)}{x-4} = x + 4\), where \(x \neq 4\). Evaluating at \(x = 6\) gives \(6 + 4 = 10\). ✓

Answer: \(\left(\dfrac{f}{g}\right)(6) = 10\)



Conclusion

In this lesson, you learned how to combine two functions using the four arithmetic operations — addition, subtraction, multiplication, and division — to create a new function rule. You explored how the type of operation affects the structure of the resulting function and discovered that while adding, subtracting, and multiplying polynomial and exponential functions typically produces a new function defined for all real numbers, dividing two functions requires careful attention to the denominator. Any input value that makes the denominator equal to zero must be excluded from the domain, and that restriction must be identified before simplifying the expression. You also practiced evaluating combined functions at a specific input value by substituting directly into the new function rule or by evaluating each function separately and then applying the operation. These skills are foundational for future work with more complex function transformations and real-world mathematical modeling, where combining multiple function types allows you to build more accurate and meaningful representations of the situations you are analyzing.
