📚 VOCABULARY

Composite Function: A function formed by applying one function to the results of another, written as \( (f \circ g)(x) = f(g(x)) \), where the output of \( g(x) \) becomes the input of \( f(x) \).

Composition of Functions: The operation of combining two functions by substituting the entire rule of one function in place of the input variable of another.

Domain: The complete set of allowable input values \( x \) for which a function is defined.

Domain Restriction: A limitation on the input values of a function, which in a composite function may arise when the range of the inner function excludes certain values that the outer function requires.

Function Notation: A symbolic way of writing a function and its operations, such as \( f(x) \) or \( f(g(x)) \), that clearly identifies the input being used and the operations being applied.

Inner Function: In a composition \( f(g(x)) \), the function \( g(x) \) is the inner function; its output becomes the input for the outer function.

Input: A value substituted into a function in place of the independent variable; in a composition, the output of the inner function serves as the input of the outer function.

Outer Function: In a composition \( f(g(x)) \), the function \( f \) is the outer function; it receives the output of the inner function as its input.

Output: The result produced by a function for a given input value; written as \( f(x) \) for a function \( f \) evaluated at \( x \).

Range: The complete set of possible output values produced by a function for all inputs in its domain.

Table of Values: An organized display of input-output pairs for a function, which can be used to represent and evaluate a composition by tracing outputs of one function as inputs into another.

💡 EXPLORING THE MATH

In this lesson, you will learn how to compose two functions — that is, how to apply one function to the output of another. You will represent compositions both algebraically and using tables of values, and you will determine the domain and range of the resulting composite function.

Finding the Composition of Two Functions Algebraically

What Is a Composition of Functions?

When you compose two functions, you use the output of one function as the input of another. Given two functions \(f(x)\) and \(g(x)\), the composition \(f(g(x))\) — also written \((f \circ g)(x)\) — means you substitute the entire rule of \(g(x)\) in place of the input variable \(x\) in \(f(x)\).

The function \(g(x)\) is called the inner function and \(f(x)\) is called the outer function. Always begin by identifying the inner function, then substitute it into the outer function and simplify.

Important: Composition is not commutative. In general, \(f(g(x)) \neq g(f(x))\). The order in which the functions are composed changes the result.


Domain and Range of a Composite Function

After writing the rule for the composite function, you must determine its domain and range.

The domain of \(f(g(x))\) is the set of all \(x\)-values that satisfy two conditions: \(x\) must be in the domain of \(g\), and the output \(g(x)\) must be in the domain of \(f\).

In practice, the most common restriction arises when the outer function is a square root — the expression inside the radical must be greater than or equal to zero. The range is determined by the set of all possible output values once the domain has been established.


Quadratic Composed with a Linear Function

Let \(f(x) = x^2 + 3\) and \(g(x) = 2x - 1\).

Find \((f \circ g)(x)\) and state the domain and range.

Step 1: Identify the inner and outer functions. Here, \(g(x) = 2x - 1\) is the inner function and \(f(x) = x^2 + 3\) is the outer function.

Step 2: Substitute \(g(x)\) into \(f(x)\) in place of \(x\).

Step 3: Expand and simplify.

Step 4: Determine the domain. Both \(f(x)\) and \(g(x)\) are defined for all real numbers, so there are no restrictions.

Step 5: Determine the range. The composite function \(4x^2 - 4x + 4\) is a parabola opening upward. Find its vertex: \(x = \dfrac{4}{2(4)} = \dfrac{1}{2}\). Evaluate: \(4\left(\dfrac{1}{2}\right)^2 - 4\left(\dfrac{1}{2}\right) + 4 = 1 - 2 + 4 = 3\). The minimum value is 3.


Answer: \((f \circ g)(x) = 4x^2 - 4x + 4\).

Domain: all real numbers as an inequality \(-\infty < x < \infty \).

Range: \([3, \infty)\) as an inequality



Square Root Composed with a Quadratic Function

Let \(f(x) = \sqrt{x}\) and \(g(x) = x^2 - 9\).

Find \((f \circ g)(x)\) and state the domain and range.

Step 1: Identify the inner and outer functions. Here, \(g(x) = x^2 - 9\) is the inner function and \(f(x) = \sqrt{x}\) is the outer function.

Step 2: Substitute \(g(x)\) into \(f(x)\).

\(f(g(x)) = f(x^2 - 9) = \sqrt{x^2 - 9}\)

Step 3: Determine the domain. Because the outer function is a square root, the expression inside the radical must be greater than or equal to zero.

\(x^2 - 9 \geq 0\)

Factor: \((x - 3)(x + 3) \geq 0\)

This inequality is satisfied when \(x \leq -3\) or \(x \geq 3\). This excludes everything between -3 and 3. Domain: \((-\infty, -3] \cup [3, \infty)\).

Step 4: Determine the range. Since \(x^2 - 9 \geq 0\) for all \(x\) in the domain, and the square root of a non-negative number is non-negative, the range begins at 0 and increases without bound.


Answer: \((f \circ g)(x) = \sqrt{x^2 - 9}\).

Domain: \((-\infty, -3] \cup [3, \infty)\) as an inequality .

Range: \([0, \infty)\) as an inequality

Example 1

Let \(f(x) = 2^x\) and \(g(x) = x - 3\).

Find \((f \circ g)(x)\) and state the domain and range.

Show Solution and Explanation

Step 1: Identify the inner and outer functions. \(g(x) = x - 3\) is the inner function and \(f(x) = 2^x\) is the outer function.

Step 2: Substitute \(g(x)\) into \(f(x)\) in place of \(x\).

\(f(g(x)) = f(x - 3) = 2^{x - 3}\)

Step 3: Check for domain restrictions. The linear function \(g(x) = x - 3\) is defined for all real numbers, and the exponential function \(f(x) = 2^x\) accepts all real numbers as input. There are no restrictions.

Step 4: Determine the range. An exponential function of the form \(2^{x-3}\) always produces positive output values, no matter what \(x\) is. The outputs get closer and closer to zero but never reach it.


Answer: \((f \circ g)(x) = 2^{x-3}\).

Domain: all real numbers .

Range: \((0, \infty)\) as an inequality \(y > 0\).



Example 2

Let \(f(x) = \sqrt{x}\) and \(g(x) = x^2 + 1 \).

Find \((g \circ f)(x)\) and state the domain and range.

Show Solution and Explanation

Step 1: Identify the inner and outer functions. \(f(x) =\sqrt{x}\) is the inner function and \(g(x) = x^2 + 1\) is the outer function.

Step 2: Substitute \(f(x)\) into \(g(x)\).

\(g(f(x)) = g(\sqrt{x}) = (\sqrt{x})^2 + 1 = x + 1\)

Step 3: Determine the domain. Even though the simplified expression \(x + 1\) looks like it is defined for all real numbers, remember that the inner function \(g(x) = \sqrt{x}\) requires \(x \geq 0\). The domain restriction must be established before simplifying. Therefore, \(x \geq 0\). Domain: \([0, \infty)\).

Step 4: Determine the range. When \(x \geq 0\), the expression \(x + 1 \geq 0 + 1 = 1\). The output increases without bound as \(x\) increases.


Answer: \((f \circ g)(x) = x + 1\), where \(x \geq 0\).

Domain: \([0, \infty)\) as an inequality \(x\geq 0\).

Range: \([1, \infty)\) as an inequality \(y \geq 1\).



Example 3

Let \(f(x) = \sqrt[3]{x}\) and \(g(x) = x^3 + 8\).

Find \((f \circ g)(x)\) and state the domain and range.

Show Solution and Explanation

Step 1: Identify the inner and outer functions. \(g(x) = x^3 + 8\) is the inner function and \(f(x) = \sqrt[3]{x}\) is the outer function.

Step 2: Substitute \(g(x)\) into \(f(x)\).

\(f(g(x)) = f(x^3 + 8) = \sqrt[3]{x^3 + 8}\)

Step 3: Determine the domain. The cubic function \(g(x) = x^3 + 8\) is defined for all real numbers. Unlike square roots, cube roots are defined for all real numbers — including negative values — so the outer function places no additional restrictions on the input. There are no domain restrictions.

Step 4: Determine the range. Since the cube root function produces all real number outputs (from \(-\infty\) to \(\infty\)) and \(g(x) = x^3 + 8\) takes on all real values, the composite function outputs all real numbers as well.


Answer: \((f \circ g)(x) = \sqrt[3]{x^3 + 8}\).

Domain: all real numbers \(-\infty < x < \infty\).

Range: all real numbers \(-\infty < y < \infty\).



Finding Compositions of Two Functions Represented as Tables

How to Use Tables to Find a Composition

When functions are represented as tables of values rather than algebraic rules, you can still find compositions by carefully tracing outputs of one function as inputs into the other. The process follows the same logic as algebraic composition: \(f(g(x))\) means you first look up \(g(x)\) in the table for \(g\), then use that output value as the input when looking up a value in the table for \(f\).

Follow these steps for any table composition:

Step 1 — Locate the input value \(x\) in the table for the inner function and read off the output.

Step 2 — Take that output and use it as the new input in the table for the outer function.

Step 3 — Read the final output. This is the value of the composition.

Domain Restriction with Tables: If the output of the inner function does not appear as an input in the outer function's table, the composition is undefined at that value. This is a domain restriction — that input value cannot be included in the domain of the composite function.


Evaluating Specific Composition Values from Tables

Finding \((f \circ g)(2)\):

  • Step 1: Look up \(g(2)\) in the table for \(g\). \(g(2) = 5\).
  • Step 2: Use 5 as input into the table for \(f\). \(f(5) = 1\).
  • \((f \circ g)(2) = 1\)

  • Step 2: \(f(6) = 3\).
  • \((f \circ g)(5) = 3\)


When a Composition Is Undefined

Using the same tables from Worked Example 1, find \((g \circ f)(1)\), \((g \circ f)(4)\), and \((g \circ f)(2)\).

Finding \((g \circ f)(1)\):

  • Step 1: Look up \(f(1)\) in the table for \(f\). \(f(1) = 4\).
  • Step 2: Use 4 as input into the table for \(g\). \(g(4) = 1\).
  • \((g \circ f)(1) = 1\)

Finding \((g \circ f)(4)\):

  • Step 1: \(f(4) = 6\).
  • Step 2: Look up \(g(6)\) in the table for \(g\). The value \(x = 6\) does not appear in the table for \(g\). The composition is undefined.
  • \((g \circ f)(4)\) is undefined. The value \(x = 4\) is not in the domain of \(g \circ f\).

Finding \((g \circ f)(2)\):

  • Step 1: \(f(2) = 7\).
  • Step 2: Look up \(g(7)\) in the table for \(g\). The value \(x = 7\) does not appear in the table for \(g\). The composition is undefined.
  • \((g \circ f)(2)\) is undefined. The value \(x = 2\) is not in the domain of \(g \circ f\).

This example illustrates an important point: when the output of the inner function falls outside the domain of the outer function, the composition cannot be evaluated at that input. These values must be excluded from the domain of the composite function.

For each input \(x\), first look up \(q(x)\), then use that value to look up \(p(q(x))\).

\((p \circ q)(0) = p(q(0)) = p(1) = 0\)

\((p \circ q)(1) = p(q(1)) = p(4) = 2\)

\((p \circ q)(2) = p(q(2)) = p(2) = 4\)

Range of \((p \circ q)(x)\): \(\{0, 1, 2, 3, 4\}\) — the set of all output values in the completed table.

Evaluating a Composition of Functions Given the Equations

How to Evaluate a Composition at a Specific Input Value

When you are given the equations of two functions and asked to evaluate a composition at a specific value, you have two methods available. Both will always produce the same answer.

Method 1 — Work from the inside out: Evaluate the inner function at the given input first, then substitute that result into the outer function.

Method 2 — Build the composite rule first: Find the algebraic rule for the composite function as you did in Part 1, then substitute the given input value into the simplified rule.

For most problems at this level, Method 1 is faster when you only need a single value. Method 2 is more efficient when you need to evaluate the composition at several different input values.

Before evaluating, always check that the given input is in the domain of the composite function. If the input is a restricted value, the composition is undefined at that point.


Evaluating Using Method 1

Let \(f(x) = x^2 - 4\) and \(g(x) = \sqrt{x + 5}\). Find \((f \circ g)(4)\).

Step 1: Identify the inner function. In \((f \circ g)(x) = f(g(x))\), the inner function is \(g(x) = \sqrt{x + 5}\).

Step 2: Evaluate the inner function at \(x = 4\).

\(g(4) = \sqrt{4 + 5} = \sqrt{9} = 3\)

Step 3: Substitute the result into the outer function \(f(x) = x^2 - 4\).

\(f(g(4)) = f(3) = (3)^2 - 4 = 9 - 4 = 5\)

Answer: \((f \circ g)(4) = 5\)

Example 6

Let \(f(x) = 3x + 2\) and \(g(x) = x^2 - 1\). Find \((g \circ f)(2)\).

Show Solution and Explanation

Step 1: In \((g \circ f)(x) = g(f(x))\), the inner function is \(f(x) = 3x + 2\). Evaluate at \(x = 2\).

\(f(2) = 3(2) + 2 = 6 + 2 = 8\)

Step 2: Substitute the result into the outer function \(g(x) = x^2 - 1\).

\(g(f(2)) = g(8) = (8)^2 - 1 = 64 - 1 = 63\)


Answer: \((g \circ f)(2) = 63\)

Note: Notice that the order matters. If you had evaluated \((f \circ g)(2)\) instead, you would get \(f(g(2)) = f(3) = 3(3) + 2 = 11\), which is a completely different result.

 

Example 7

Let \(f(x) = 2^x\) and \(g(x) = \sqrt[3]{x - 1}\). Find \((f \circ g)(9)\).

Show Solution and Explanation

Step 1: In \((f \circ g)(x) = f(g(x))\), the inner function is \(g(x) = \sqrt[3]{x - 1}\). Evaluate at \(x = 9\).

\(g(9) = \sqrt[3]{9 - 1} = \sqrt[3]{8} = 2\)

Step 2: Substitute the result into the outer function \(f(x) = 2^x\).

\(f(g(9)) = f(2) = 2^2 = 4\)


Answer: \((f \circ g)(9) = 4\)

Note: The cube root function is defined for all real numbers, and the exponential function accepts all real inputs, so there are no domain concerns here. The input \(x = 9\) is valid.

 

Conclusion

In this lesson, you learned how to compose two functions by substituting the rule or output of one function into another. When working algebraically, you practiced substituting the inner function into the outer function and simplifying the result, using linear, quadratic, cubic, exponential, square root, and cube root function types. You also learned that the domain of a composite function requires careful attention — any restriction from the inner function carries forward, and the outer function may impose additional restrictions, particularly when it contains a square root. When working with tables, you traced outputs of the inner function as inputs to the outer function and discovered that a composition is undefined whenever the inner function's output is not found in the domain of the outer function's table. Throughout both representations, you saw that order matters: \(f(g(x))\) and \(g(f(x))\) generally produce different results. These skills form the foundation for deeper work with inverse functions and advanced function analysis in future lessons.
