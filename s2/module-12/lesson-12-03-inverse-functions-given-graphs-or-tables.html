📚 VOCABULARY

Horizontal Line Test: A visual method used to determine whether a function is one-to-one: if every horizontal line intersects the graph of the function at most once, the function passes the test and an inverse function exists.

Input: A value substituted into a function in place of the independent variable, represented as \( x \) in the notation \( f(x) \); in an inverse function, the original output becomes the new input.

Inverse Function: A function that reverses the input-output relationship of the original function, written as \( f^{-1}(x) \), such that \( f(f^{-1}(x)) = x \) and \( f^{-1}(f(x)) = x \) for all \( x \) in the appropriate domain.

Line of Reflection \( y = x \): The diagonal line over which a function and its inverse are mirror images of each other on a coordinate plane; reflecting any point \( (a, b) \) over this line produces the point \( (b, a) \).

One-to-one Function: A function in which every output value corresponds to exactly one input value; that is, if \( f(a) = f(b) \), then \( a = b \). A function must be one-to-one for its inverse to also be a function.

Output: The result produced by a function for a given input, written as \( f(x) \); in an inverse function, the original output becomes the new input.

Symmetry: In the context of inverse functions, the graphical property that the graph of \( f^{-1}(x) \) is a reflection of the graph of \( f(x) \) across the line \( y = x \).

Vertical Line Test: A visual method used to confirm that a graph represents a function: if every vertical line intersects the graph at most once, the graph represents a function. Passing this test alone does not guarantee the existence of an inverse function; the Horizontal Line Test must also be applied.

💡 EXPLORING THE MATH

In this lesson, you will learn how to determine whether a function has an inverse by examining its graph or table of values. If an inverse exists, you will represent it graphically by reflecting over the line \( y = x \), or as a table by swapping inputs and outputs. These skills build on your understanding of one-to-one functions and prepare you for verifying inverses algebraically in the next lesson.

What is an Inverse Function?

A function that reverses the input-output relationship of the original function, written as \( f^{-1}(x) \), such that \( f(f^{-1}(x)) = x \) and \( f^{-1}(f(x)) = x \) for all \( x \) in the appropriate domain.

The original function is denoted with \(f(x) \) and its inverse is denoted as \(f^{-1}(x) \).

Using Graphs to Determine Whether a Function Has an Inverse

The Horizontal Line Test

For a function to have an inverse that is also a function, it must be one-to-one — every output value is produced by exactly one unique input value. On a graph, you can check this with the Horizontal Line Test.

Horizontal Line Test: If every horizontal line you could draw across the coordinate plane intersects the graph at most once, the function is one-to-one and an inverse function exists. If any horizontal line intersects the graph more than once, the function is not one-to-one, and an inverse function does not exist (without restricting the domain).

Do not confuse this with the Vertical Line Test, which confirms that a graph represents a function at all.


Representing the Inverse Graphically

If a function passes the Horizontal Line Test, its inverse can be drawn by reflecting the original graph over the line \( y = x \). This reflection swaps every coordinate pair: a point \( (a, b) \) on the original function maps to the point \( (b, a) \) on the inverse. The line \( y = x \) acts as a mirror between the two graphs.


Determining and Creating an Inverse From a Graph

Let the graph shown represent \( f(x) \). Apply the Horizontal Line Test to determine whether an inverse function exists, and if so, represent the inverse graphically.

Step 1 — Apply the Horizontal Line Test (HLT). Since \( f(x) \) appears as a linear function with a nonzero slope, it is strictly increasing. Every horizontal line will cross this graph exactly once. The function passes the Horizontal Line Test and is one-to-one. An inverse function exists.


The orange dashed horizontal lines each cross f(x) exactly once — the function passes the Horizontal Line Test.

Step 2 — Reflect over \( y = x \) to represent the inverse. Reflect the graph of \( f(x) \) (green) over the line \( y = x \) (gray, dashed) to obtain the graph of \( f^{-1}(x) \) (orange). Every point \( (a, b) \) on the original becomes the point \( (b, a) \) on the inverse — for example, the point \( (0, -1) \) on \( f(x) \) corresponds to the point \( (-1, 0) \) on \( f^{-1}(x) \), and the point \( (2, 3) \) corresponds to \( (3, 2) \).

Using Tables to Determine Whether a Function Has an Inverse

How to Check a Table for a One-to-One Function

When a function is given as a table of values, you determine whether it is one-to-one by examining the output column. If every output value in the table is unique — no output appears more than once — the function is one-to-one and an inverse exists.

Rule for Tables: Scan the output column. If all values are different, the function is one-to-one and an inverse function exists. To represent the inverse, swap the input and output columns. If any output value repeats, the function is not one-to-one and an inverse function does not exist.


A Function That Has an Inverse

Examine the table and determine whether the function is one-to-one. If so, construct the inverse table.

x f(x)
1 4
2 7
3 10
4 13
5 16

Step 1 — Check for repeated outputs. The output values are 4, 7, 10, 13, and 16. All five values are distinct — no output repeats. The function is one-to-one, and an inverse function exists.

Step 2 — Construct the inverse table. Swap the input and output columns. The original output values become the new inputs, and the original inputs become the new outputs.

x f ⁻¹(x)
4 1
7 2
10 3
13 4
16 5

The inverse reverses every input-output pair. Since \( f(3) = 10 \), we confirm \( f^{-1}(10) = 3 \). ✓


A Function That Does Not Have an Inverse

Examine the table and determine whether the function is one-to-one.

x g(x)
−2 3
−1 7
0 3
1 9
2 12

Step 1 — Check for repeated outputs. The output values are 3, 7, 3, 9, and 12. The output value 3 appears twice — for both \( x = -2 \) and \( x = 0 \). This means \( g(-2) = g(0) = 3 \). The function is not one-to-one.

Step 2 — Conclude. Because two different inputs share the same output, an inverse function does not exist. If you tried to swap the columns, the input value 3 in the new table would have two different outputs (−2 and 0), which violates the definition of a function.

Conclusion

In this lesson, you explored two representations for determining whether a function has an inverse and how to construct that inverse. Using graphs, you applied the Horizontal Line Test — if every horizontal line crosses the graph at most once, the function is one-to-one and an inverse exists. You then represented that inverse graphically by reflecting the original curve over the line \( y = x \), observing how every point \( (a, b) \) on the original corresponds to the point \( (b, a) \) on the inverse. Using tables, you checked the output column for repeated values — if all outputs are unique, the function is one-to-one and you can construct the inverse table by swapping the input and output columns. When a function fails either test, as you saw with \( f(x) = x^2 \), no inverse function exists over the full domain. Both methods reflect the same core idea: a function must be one-to-one for its inverse to also be a function. In the next lesson, you will build on these ideas by learning to verify inverse functions algebraically using composition of functions.
