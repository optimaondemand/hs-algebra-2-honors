📚 VOCABULARY

Bijective Function: A function that is both one-to-one (each input maps to a unique output) and onto (every possible output is produced by some input); a bijective function always has an inverse that is also a function.

Domain Restriction: A limitation placed on the input values of a function to ensure it is one-to-one; when finding the inverse of a function that is not one-to-one over all real numbers, a domain restriction is required before the inverse can be written.

Function Type: A classification of a function based on its algebraic structure (e.g., linear, quadratic, exponential, radical, cubic) that can be used to determine whether the function is one-to-one and whether an inverse function exists without graphing.

Identity Function: The function \( I(x) = x \), which returns every input unchanged; used as the benchmark for verifying inverse functions, since \( f(f^{-1}(x)) = x \) and \( f^{-1}(f(x)) = x \) must both hold.

Inverse Function: A function that reverses the input-output relationship of the original function, written as \( f^{-1}(x) \), found algebraically by replacing \( f(x) \) with \( y \), swapping \( x \) and \( y \), and solving for \( y \).

One-to-one Function: A function in which every output value corresponds to exactly one input value; that is, if \( f(a) = f(b) \), then \( a = b \). Only one-to-one functions have inverses that are also functions.

Verification by Composition: The process of confirming that two functions \( f(x) \) and \( g(x) \) are inverses by showing that both \( f(g(x)) = x \) and \( g(f(x)) = x \) for all \( x \) in the appropriate domain.

\( x \)-\( y \) Interchange: The algebraic step in finding an inverse function where the variables \( x \) and \( y \) are swapped in the equation, reflecting the reversal of the input-output relationship before solving for the new output variable.

💡 EXPLORING THE MATH

In the previous lesson, you learned how to determine whether an inverse function exists by examining graphs and tables. In this lesson, you will work directly with equations. You will learn how to analyze the algebraic structure of a function to determine whether it is one-to-one, find the equation of its inverse when one exists, and verify the inverse relationship using composition of functions.

Determining Whether a Function Has an Inverse from Its Equation

Using Function Type to Determine One-to-One Behavior

  • Recall that a function must be one-to-one for its inverse to also be a function.
  • When you are given an equation rather than a graph or table, you can determine whether the function is one-to-one by analyzing its function type — the algebraic structure that classifies it as linear, quadratic, exponential, and so on.
  • Each function type has predictable behavior that tells you whether it is strictly increasing or decreasing (one-to-one) or whether it turns around and revisits output values (not one-to-one).

The table below summarizes the most common function types you will encounter and whether each has an inverse over its natural domain.

Function Type General Form One-to-One? Inverse Exists?
Linear (nonzero slope) \( f(x) = mx + b,\ m \neq 0 \) Yes Yes
Quadratic \( f(x) = ax^2 + bx + c \) No Not without a domain restriction
Cubic (Basic Forms and Transformation Form)

\( f(x) = ax^3 + \cdots \)

\(f(x)=a(x+h)^3-k \)

 Yes (for basic forms) Yes
Cubic \( f(x)=ax^3+bx^2+ \cdots \) No (graph will turn around) No
Exponential \( f(x) = ab^x,\ b > 0,\ b \neq 1 \) Yes Yes
Square Root \( f(x) = \sqrt{x} \) Yes (natural domain \( x \geq 0 \)) Yes
Cube Root \( f(x) = \sqrt[3]{x} \) Yes (all real numbers) Yes
Logarithmic \( f(x) = \log_b(x),\ b > 0,\ b \neq 1 \) Yes (natural domain \( x > 0 \)) Yes
Absolute Value \( f(x) = |x| \) No Not without a domain restriction

Key Idea: A function is one-to-one if it is strictly increasing or strictly decreasing across its entire domain — it never "turns around." Linear, basic cubic, exponential, and square root functions all have this property. Quadratic and absolute value functions are symmetric about a vertex or axis, which means they return the same output value for two different inputs and are therefore not one-to-one over all real numbers. Some Cubic functions are also symmetric about a point.
Using graphs of functions can help to determine if a function is strictly increasing or decreasing, or if it turns around at any point.

Important Note on Quadratic Functions: Although a quadratic function does not have an inverse over all real numbers, an inverse can exist if the domain is restricted to one side of the vertex — for example, limiting \( f(x) = x^2 \) to \( x \geq 0 \) makes it one-to-one. Unless a domain restriction is explicitly given, assume a quadratic function does not have an inverse.


Steps for Finding the Algebraic Inverse of a Function

Once you have confirmed that a function is one-to-one, follow these four steps to find the equation of its inverse.

Step 1 — Replace \( f(x) \) with \( y \) to make the equation easier to work with.
Step 2 — Swap \( x \) and \( y \). This reflects the reversal of the input-output relationship that defines an inverse function.
Step 3 — Solve the new equation for \( y \) using algebraic properties.
Step 4 — Replace \( y \) with \( f^{-1}(x) \) to write the inverse in proper function notation. State any domain restrictions if needed.


A Function That Has an Inverse

Determine whether \( f(x) = 3x - 5 \) has an inverse. If so, find the equation of the inverse.

  • Step 1 — Identify the function type. \( f(x) = 3x - 5 \) is a linear function with slope \( m = 3 \neq 0 \). Linear functions with nonzero slopes are always strictly increasing or strictly decreasing, making them one-to-one. An inverse function exists.
  • Step 2 — Replace \( f(x) \) with \( y \).
    • \( y = 3x - 5 \)
  • Step 3 — Swap \( x \) and \( y \).
    • \( x = 3y - 5 \)
  • Step 4 — Solve for \( y \).
  • Step 5 — Write in inverse notation.
    • \( f^{-1}(x) = \dfrac{x + 5}{3} \)

Domain check: Both \( f(x) \) and \( f^{-1}(x) \) are linear functions defined for all real numbers. No domain restriction is needed.

Answer: \( f^{-1}(x) = \dfrac{x + 5}{3} \). Domain: all real numbers.


A Function That Does Not Have an Inverse

Determine whether \( g(x) = x^2 - 4 \) has an inverse over all real numbers.

Step 1 — Identify the function type. \( g(x) = x^2 - 4 \) is a quadratic function. A quadratic function is a parabola that is symmetric about its vertex. Because it is symmetric, every output value above the minimum is produced by two different input values.

Step 2 — Identify specific inputs that share an output. Consider \( x = 3 \) and \( x = -3 \):

\( g(3) = (3)^2 - 4 = 9 - 4 = 5 \)

\( g(-3) = (-3)^2 - 4 = 9 - 4 = 5 \)

Both \( x = 3 \) and \( x = -3 \) produce the output 5. Since two different inputs share the same output, the function is not one-to-one.

Answer: \( g(x) = x^2 - 4 \) is not one-to-one over all real numbers. An inverse function does not exist without restricting the domain.

Example 1

Determine whether \( f(x) = \dfrac{1}{2}x + 4 \) has an inverse. If so, find the equation of the inverse.

Show Answer and Explanation

Function type: \( f(x) = \dfrac{1}{2}x + 4 \) is a linear function with slope \( m = \dfrac{1}{2} \neq 0 \). It is one-to-one, and an inverse exists.

Step 1: Replace \( f(x) \) with \( y \).

  • \( y = \dfrac{1}{2}x + 4 \)

Step 2: Swap \( x \) and \( y \).

  • \( x = \dfrac{1}{2}y + 4 \)

Step 3: Solve for \( y \). Subtract 4 from both sides. Then multiply both sides by 2.

Step 4: Write in inverse notation.

  • \( f^{-1}(x) = 2x - 8 \)

Answer: \( f^{-1}(x) = 2x - 8 \). Domain: all real numbers.

Notice: The original function has slope \( \dfrac{1}{2} \) and the inverse has slope 2. The slopes of a function and its inverse are always reciprocals of each other — a useful pattern to check your work.

 

Example 2

Determine whether \( f(x) = x^3 + 2 \) has an inverse. If so, find the equation of the inverse.

Show Answer and Explanation

Function type: \( f(x) = x^3 + 2 \) is a cubic function. Basic cubic functions are strictly increasing across all real numbers — the cube of a larger number is always larger than the cube of a smaller number. No two different inputs produce the same output. The function is one-to-one, and an inverse exists.

Step 1: Replace \( f(x) \) with \( y \).

  • \( y = x^3 + 2 \)

Step 2: Swap \( x \) and \( y \).

  • \( x = y^3 + 2 \)

Step 3: Solve for \( y \). Subtract 2 from both sides.

  • \( x - 2 = y^3 \)
  • Take the cube root of both sides. Unlike square roots, cube roots are defined for all real numbers, so no restriction is needed.
  • \( y = \sqrt[3]{x - 2} \)

Step 4: Write in inverse notation.

  • \( f^{-1}(x) = \sqrt[3]{x - 2} \)

Answer: \( f^{-1}(x) = \sqrt[3]{x - 2} \). Domain: all real numbers.

 

Example 3

Determine whether \( h(x) = 2^x - 3 \) has an inverse. If so, find the equation of the inverse.

Show Answer and Explanation

Function type: \( h(x) = 2^x - 3 \) is an exponential function. Exponential functions with a base greater than 1 are strictly increasing — as \( x \) increases, \( 2^x \) always increases. Subtracting 3 shifts the graph down but does not change this behavior. The function is one-to-one, and an inverse exists.

Step 1: Replace \( h(x) \) with \( y \).

  • \( y = 2^x - 3 \)

Step 2: Swap \( x \) and \( y \).

  • \( x = 2^y - 3 \)

Step 3: Solve for \( y \). Add 3 to both sides.

  • \( x + 3 = 2^y \)
  • To isolate \( y \), apply a logarithm base 2 to both sides. The logarithm is the inverse operation of an exponential.
  • \( y = \log_2(x + 3) \)

Step 4: Write in inverse notation.

  • \( h^{-1}(x) = \log_2(x + 3) \)

Domain check: The argument of a logarithm must be positive, so \( x + 3 > 0 \), which means \( x > -3 \). This restriction comes from the fact that the original exponential function \( h(x) = 2^x - 3 \) has a range of \( (-3, \infty) \) — the inverse's domain must match the original function's range.

Answer: \( h^{-1}(x) = \log_2(x + 3) \), where \( x > -3 \).

Verifying Inverse Functions Using Composition

Why Verify?

Finding an inverse algebraically using the four-step process gives you a strong candidate for the inverse function, but it is possible to make an algebraic error along the way. Verifying the result using composition of functions gives you a definitive, conclusive confirmation that two functions are truly inverses of each other — not just a visual estimate from a graph or a pattern noticed in a table.

Verification Rule: Two functions \( f(x) \) and \( g(x) \) are inverses of each other if and only if both of the following are true:

\( f(g(x)) = x \) for all \( x \) in the domain of \( g \)
\( g(f(x)) = x \) for all \( x \) in the domain of \( f \)

Both compositions must equal the identity function \( I(x) = x \). If even one of them does not simplify to \( x \), the two functions are not inverses.

Why Must You Check Both Directions?

For most well-behaved functions at this level, if one composition equals \( x \), the other will as well — but this is not guaranteed in all cases, particularly when domain restrictions are involved. Checking both directions is a mathematical habit of precision that protects against errors and is expected on assessments.



Steps for Verifying Inverse Functions by Composition

Step 1 — Compute \( f(g(x)) \) by substituting the entire rule of \( g(x) \) into \( f(x) \) in place of \( x \), then simplify completely.
Step 2 — Compute \( g(f(x)) \) by substituting the entire rule of \( f(x) \) into \( g(x) \) in place of \( x \), then simplify completely.
Step 3 — If both compositions simplify to \( x \), the functions are inverses. If either composition does not simplify to \( x \), the functions are not inverses.



Verifying an Inverse Relationship

Determine algebraically whether \( f(x) = 4x - 7 \) and \( g(x) = \dfrac{x + 7}{4} \) are inverses of each other.

Step 1 — Compute \( f(g(x)) \). Substitute \( g(x) = \dfrac{x + 7}{4} \) into \( f(x) = 4x - 7 \) in place of \( x \).

\( f(g(x)) = 4\left(\dfrac{x + 7}{4}\right) - 7 \)

Multiply: the 4 in the numerator and the 4 in the denominator cancel.

\( f(g(x)) = (x + 7) - 7 = x \) ✓

Step 2 — Compute \( g(f(x)) \). Substitute \( f(x) = 4x - 7 \) into \( g(x) = \dfrac{x + 7}{4} \) in place of \( x \).

\( g(f(x)) = \dfrac{(4x - 7) + 7}{4} \)

Combine like terms in the numerator.

\( g(f(x)) = \dfrac{4x}{4} = x \) ✓

Step 3 — Conclude. Both \( f(g(x)) = x \) and \( g(f(x)) = x \). The two functions are confirmed to be inverses of each other.

Example 4

Determine algebraically whether \( f(x) = x^3 - 5 \) and \( g(x) = \sqrt[3]{x + 5} \) are inverses of each other.

Show Answer and Explanation

Compute \( f(g(x)) \). Substitute \( g(x) = \sqrt[3]{x + 5} \) into \( f(x) = x^3 - 5 \).

\( f(g(x)) = \left(\sqrt[3]{x + 5}\right)^3 - 5 \)

Raising a cube root to the third power cancels the radical.

\( f(g(x)) = (x + 5) - 5 = x \) ✓

Compute \( g(f(x)) \). Substitute \( f(x) = x^3 - 5 \) into \( g(x) = \sqrt[3]{x + 5} \).

\( g(f(x)) = \sqrt[3]{(x^3 - 5) + 5} \)

Combine like terms inside the radical.

\( g(f(x)) = \sqrt[3]{x^3} = x \) ✓

Answer: Both compositions equal \( x \). \( f(x) = x^3 - 5 \) and \( g(x) = \sqrt[3]{x + 5} \) are inverses of each other.

Note: This result makes sense — when you apply the four-step algebraic method to \( f(x) = x^3 - 5 \), the inverse you find is exactly \( g(x) = \sqrt[3]{x + 5} \). Composition confirms what the algebra predicted.

 

Example 5

Determine algebraically whether \( f(x) = 3x + 6 \) and \( g(x) = \dfrac{x}{3} - 6 \) are inverses of each other.

Show Answer and Explanation

Compute \( f(g(x)) \). Substitute \( g(x) = \dfrac{x}{3} - 6 \) into \( f(x) = 3x + 6 \).

\( f(g(x)) = 3\left(\dfrac{x}{3} - 6\right) + 6 \)

Distribute the 3.

\( f(g(x)) = x - 18 + 6 = x - 12 \)

Since \( x - 12 \neq x \), we already know these functions are not inverses. There is no need to check the second composition, though we will do so for completeness.

Compute \( g(f(x)) \). Substitute \( f(x) = 3x + 6 \) into \( g(x) = \dfrac{x}{3} - 6 \).

\( g(f(x)) = \dfrac{(3x + 6)}{3} - 6 \)

Divide each term in the numerator by 3.

\( g(f(x)) = x + 2 - 6 = x - 4 \)

Again, \( x - 4 \neq x \). ✗

Answer: Neither composition equals \( x \). \( f(x) = 3x + 6 \) and \( g(x) = \dfrac{x}{3} - 6 \) are not inverses of each other.

Where did \( g(x) \) go wrong? To find the correct inverse of \( f(x) = 3x + 6 \), apply the four-step process: swap and solve to get \( x = 3y + 6 \Rightarrow y = \dfrac{x - 6}{3} \). The correct inverse is \( f^{-1}(x) = \dfrac{x - 6}{3} \), not \( \dfrac{x}{3} - 6 \). The error in \( g(x) \) was subtracting 6 after dividing, rather than subtracting 6 first and then dividing — a common order-of-operations mistake.



Conclusion

In this lesson, you learned how to determine whether a function has an inverse by analyzing its equation directly, without needing a graph or table. By identifying the function type — linear, quadratic, cubic, exponential, square root, or absolute value — you can quickly assess whether the function is one-to-one and whether an inverse function exists. When an inverse does exist, you found it algebraically by following a consistent four-step process: replacing \( f(x) \) with \( y \), swapping \( x \) and \( y \) to reflect the reversal of the input-output relationship, solving for \( y \), and writing the result using inverse function notation. You also saw that domain restrictions matter — the natural domain of the inverse must align with the range of the original function, particularly for exponential and radical functions. Quadratic and absolute value functions, while extremely common, are not one-to-one over all real numbers and therefore do not have an inverse unless the domain is restricted first. In Part 2 of this lesson, you extended that work by learning how to verify an inverse relationship using composition of functions. By computing both \( f(g(x)) \) and \( g(f(x)) \) and confirming that both simplify to \( x \), you can conclusively confirm — or disprove — that two functions are inverses of each other. As Practice Problem 2 demonstrated, composition is a powerful error-detection tool: even a small structural mistake in the inverse equation will cause the composition to produce something other than \( x \), immediately revealing the error. Together, the algebraic method for finding inverses and the compositional method for verifying them give you a complete and rigorous toolkit for working with inverse functions.
