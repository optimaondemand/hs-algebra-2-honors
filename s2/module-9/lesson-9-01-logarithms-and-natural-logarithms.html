💡 EXPLORING THE MATH

In previous math courses, you learned how exponential functions model repeated multiplication and rapid growth or decay. In Algebra 2, logarithms are introduced as a way to undo exponential functions and answer a different type of question: What exponent produces a given value? This lesson will guide you step by step through what logarithms are, how they relate to exponential functions, how to rewrite expressions using logarithmic properties, and how to evaluate and approximate logarithmic expressions. Both common logarithms (base 10) and natural logarithms (base \(e\)) will be included throughout the lesson.

Converting between exponential and logarithmic forms is a direct application of the inverse relationship. The structure must remain consistent:

Evaluating Exact Values of Logarithms

Evaluating a logarithm exactly means finding the exponent without using a calculator. This is done by recognizing known powers of the base.

Use the definition:

if and only if

Ask yourself: "b to what power will make x?"


Example:

Evaluate \(\log_{2}{16}\).

Always start with your base.

Using that base, ask yourself, "2 to what power will make 16?"

\(2^4=16\)

Therefore, \(\log_{2}{16}\) equals 4.

Answer: 4


Remember:

Radicals create rational powers.

Negative Powers create fractions.

Example 1

Evaluate \(\log_{25}{5}\).

Solution:

What power of 25 will make 5?

We know that \(\sqrt{25}=5\) and roots are rational powers.

So, \(25^{1/2}=5\).

Therefore, \(\log_{25}{5}\) equals \(1/2\).

Answer: \(1/2\)



Example 2

Evaluate \(\log_{2}{\frac{1}{8}}\).

Solution:

What power of 2 will make \(1/8\)?

We know that \(2^3 = 8\) and to get a fraction, the power needs to be negative.

So, \(2^{-3}=1/8\).

Therefore, \(\log_{2}{\frac{1}{8}}\) equals \(-3\).

Answer: \(-3\)



Example 3

Evaluate \(\log{10,000}\).

Solution:

Remember the base of a common log is 10.

So, what power of 10 will make \(10,000\)?

We can count the zeros since \(10^2=10\cdot 10=100\), which has 2 zeros.

So, \(10^{4}=10,000\).

Therefore, \(\log{10,000}\) equals \(4\).

Answer: \(4\)

Properties of Logarithms

Several properties help simplify or evaluate logarithmic expressions.

 

Property

 Logarithm Common Logarithm Natural Logarithm

Zero Property

This property works because any base raised to the power of 0 equals 1.

 = \(\Large 0\) \(\Large \log{1}\) = \(\Large 0\) \(\Large \ln{1}\) = \(\Large 0\)

Identity Property

This works because any base raised to the first power equals itself.

 \(\Large \log_{b}{b}\) = \(\Large 1\) \(\Large \log{10}\) = \(\Large 1\) \(\Large \ln{e}\) = \(\Large 1\)

Inverse Property

\(\Large \log_{b}{b^x}\) = \(x\)

or

\(\Large b^{\log_{b}{x}}\) = \(x\)

\(\Large \log{10^x}\) = \(x\)

or

\(\Large 10^{\log{x}}\) = \(x\)

\(\Large \ln{e^x}\) = \(x\)

or

\(\Large e^{\ln{x}}\) = \(x\)

 

Example of Zero Property:

Evaluate \(\log_{7}{1}\).

  • Using the zero property, \(\log_{7}{1}\) equals 0 since any number to the 0 power equals 1.

Answer: 0

 

Example of Identity Property:

Evaluate \(\log_{5}{5}\).

  • Using the identity property, 5 to the 1 power equals 5.

Answer: 1

 

Example of Inverse Property:

Evaluate \(\log_{7}{7^8}\).

  • Using the inverse property, the base 7 of the log cancels out the base 7 of the argument.

Answer: 8

Conclusion

Logarithms provide a powerful way to reverse exponential functions and answer questions about unknown exponents. In this lesson, you learned how logarithmic functions relate to exponential functions, how to move between exponential and logarithmic forms, how to find exact and approximate logarithmic values, and how to use key logarithmic properties to simplify expressions. Mastery of these skills builds a strong foundation for solving exponential and logarithmic equations and for applying mathematics to real-world growth and decay models you will encounter later in Algebra 2 and beyond.
